## 不做清单（这次明确砍掉）

- 首领、精英、远程敌人、冲锋敌人
- 局外成长 / 永久数值成长（连"轻量"也不做）
- 穿刺、分叉、残影、校准卡（属 P2，不在主线）
- 18 项强化卡池
- 多场景、剧情、存档、联网
- URP、后处理、新 Input System、Cinemachine、第三方插件
- 通用技能框架 / 事件总线 / 数据驱动卡池
