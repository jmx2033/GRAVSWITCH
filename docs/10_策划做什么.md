# 10 · 策划在这个项目里做什么

> 给马权。这个项目只有 6 个人、8 天，策划的活不是一个职位说明书，是四条具体的产出。

## 一、一句话定位

**策划不是想点子的人，是唯一对「什么算做完」下定义的人。**

程序判断「能不能实现」，美术判断「好不好看」，只有你判断「这一版算不算完成、能不能给别人玩、要不要砍」。

所以你的产出必须满足一个条件：**别人拿到就能直接用**。

- ✅「关 2 的 c4–c7 是四格空档，中间放一个朝右的重力区」——程序能摆，美术能画
- ❌「关 2 要让人感觉到重力的巧妙」——谁也不知道该做什么

## 二、你的产出只有四样，别的都不是你的活

| # | 产出 | 交期 | 落在哪 |
|---|---|---|---|
| 1 | **四关格子图** | 11/1 晚上 | `03_四关设计.md` |
| 2 | **每日裁决**：今天什么算做完、什么砍 | 每天 23:00 | 群里一句话 |
| 3 | **试玩记录 → 参数改动** | 11/2 起每晚一条 | `05_会议记录/` |
| 4 | **答辩脚本 3 分钟** | 11/8 上午 | `07_答辩大纲.md` |

代码、美术、参数，一样都不是你的。**你写一行代码，珈百璃要读一行才能接，比他自己写慢两倍。**

## 三、每天固定三件事，合计不超过 40 分钟

| 时间 | 动作 | 目的 |
|---|---|---|
| 早上 | 看昨晚 push 了什么（`git log --oneline --since=yesterday`） | 知道真实进度，不靠问 |
| 中午/晚上 | 跑到最新包，**自己玩 3 遍**，只记 1 条 | 你是唯一的玩家视角 |
| 睡前 | 在群里写明天「做完」的标准，一句话 | 让五个人知道明天交什么 |

第三条最关键。**不写标准，第二天每个人对「做完」的理解都不一样**，晚上收上来的东西要返工。

## 四、试玩反馈怎么翻译（策划最难的技能）

玩家说的永远是**感觉**，你要判断它是**参数**、**引导**还是**内容**。判断错了，改的地方就全错。

| 玩家说 | 通常真实含义 | 改哪里 |
|---|---|---|
| 「跳得太飘」 | 滞空太久，重力加速度偏小 | **参数**（`01` 第五节），不是关卡 |
| 「我明明按了跳」 | 土狼时间或跳预输入没生效 | **参数**，不是设计缺陷 |
| 「这关太难」 | 前 3 秒没给提示，玩家不知道要干嘛 | **引导**（摆一个显眼的色块），不是降难度 |
| 「不知道往哪走」 | 缺视觉引导 | **美术**（重力区颜色 + 边界加亮 + 石粒），不是改布局 |
| 「好无聊」 | 缺反馈：没有音效、没有震屏、死亡没表现 | **表现**，不是加机制 |
| 「能不能加个 boss」 | 他想看到「像个游戏」，不是真想要 boss | **完成度**（主菜单、结算页），不是加内容 |
| 「玩不懂」 | 教学关教了两件事 | **关卡顺序**，见 `03` 第三节 |

**90% 的「不好玩」不是设计问题。** 大一新生试玩时说的第一句话，八成能靠改一个数字或加一个音效解决。先怀疑参数和表现，最后才怀疑关卡。

## 五、砍需求的判据（每天都会遇到）

三条同时成立，才砍：

1. 它需要**新机制**（不只是新摆位）
2. 它的工时 **超过 3 小时**
3. 它不在 P0/P1 清单里（`01` 第七节）

砍的时候说具体日期，不说「以后」：

```
记进 08_以后再说，11/8 15:00 之后再说。
```

「以后再说」等于没砍，第二天他还会问一遍。

## 六、你现在的时间表（写死，不靠感觉）

| 时间 | 你要交的 |
|---|---|
| **10/31 今晚** | 关 1、2、3 各一句话（教什么），再画三张 20×11 格子草稿 |
| **11/1（唯一整天）** | 三关在 Godot 里用 `TileMapLayer` 摆完（第一关先让程序陪摆一遍当模板），自己连续跑 3 遍，改到都能过 |
| 11/2–11/6 晚 | 每晚：跑到最新包玩 3 遍，记 1 条。**不开新坑** |
| 11/7 | 只做验收。跑完四关，列 bug 清单，不设计新东西 |
| 11/8 上午 | 答辩彩排 2 遍，掐表 |

11/1 是唯一能连续干一整天的日子。**那一整天的产出应该是三关能跑通，不是三关画得漂亮。**

## 七、三件别做的事

**1. 别自己写代码。**
你写的东西珈百璃要读、要改、要接着维护。他今晚到 11/8 的时间是全队最紧的，别给他加阅读量。

**2. 别改别人的参数。**
手感参数只有珈百璃能改。你偷偷把重力调大试了试觉得好，他下次一比对就不知道哪个是准的，两个人调的会互相抵消。

**3. 别在群里问「进度怎么样」。**
这个问题没人会答，也没人答得准。改成：**「今晚 23:00 前 push 了吗」**——有或没有，二选一，还能自己去仓库核对。

## 八、一句话记住

程序看的是碰撞盒，美术看的是色板，只有你在看**玩起来什么感觉**。

这件事没人能替你，所以别把时间花在别人也能做的事上——尤其是别把时间花在「等别人做完」上。
