GRAVSWITCH · 像素美术规格

重力主题 2D 平台跳跃解谜 · Godot 4.7.2 · 8 天实训项目 · 这份看完就能开工

一、四句话定调

主题是地心洞穴的间隙——地壳深处裂开的一条缝，上下都是岩壁。这个主题成立，而且是 8 天里最省钱的选择。但有四条必须先说清。

1. 做「亮的洞穴」，不做「暗的洞穴」

洞穴天然让人想到黑暗，但 2D 像素做光照（点光源、暗角、雾气）成本极高，而且会直接破坏玩法——玩家必须一眼看清磁场往哪个方向。所以纵深靠三档色调分层：近景亮、中景中、远景暗。不画光。

2. 做「色块洞穴」，不做「写实岩石」，而且是 Q 版

岩石纹理是最容易画成墙纸的东西：拼十格就看出重复。地形只用 6 种 tile，靠轮廓不齐 + 三档明度 + 切角区分，不靠纹理细节。Q 版指的是比例（2 头身）和圆角，不是细节量——Q 版会让画面更简单，不是更复杂。

3. 颜色只编码三件事

紫 = 磁场（改重力），橙 = 危险，青 = 你。方向靠箭头，不靠颜色。四向各配一色看起来聪明，实际是让玩家记四个含义、让你们多画四套素材。

4. 全场只有磁场会动

世界是死的，磁场是活的。这一条同时解决两个问题：一眼能看出「哪块地方特殊」，以及不会因为满屏都在动而看不清方位。

加色规则

可以加。新色接着往下排（P13、P14…），写进上表并注明用在哪，然后过这一条：

把画面转成灰度，玩家、重力区、尖刺三样必须还能分开。分得开就加，分不开就不许加。

这条不是审美要求，是玩法要求：玩家靠颜色判断「这里有重力」「这个会死」。灰度分不开，色盲玩家分不出，路演投影仪上也会糊成一片。

底色已改过：从 #0B0E14 换成 #100D14。原来那个是冷蓝黑，配太空题材用的；现在是地心洞穴，岩壁是暖紫棕，冷底会把画面压灰，而且玩家是青色，跟冷底同色系会融进去。换成暖紫黑之后，青色玩家在暗处是跳出来的。

四、角色 · 青色宝石小人

青色宝石小人 · 20 × 28，放大 4 倍看

玩家是什么（11/1 定）：一块被磁化了、会走路会跳的青色宝石小人。这一句同时解决两件事——形状有了，机制也解释了：磁性在他身上，不用再给他挂道具。他进磁场就被拉走，因为他自己就是那块磁石。

宝石感全靠一条对角线：亮面 #7FE8FF 压左上，暗面 #3A8FA8 压右下，头和身各一条，不描第二层边、不做渐变。20×28 放不下三层切面，切多了就是噪点。

光永远从左上来。倒过来站天花板时不改亮暗——改了等于多画一套图，玩家还会以为人翻面了。

只用 3 个颜色：主色 #7FE8FF、暗部兼描边 #3A8FA8、一处高光 #F2F5FF。体积靠形状和那条对角线出，不靠渐变。

脸只有两个点。眼睛是 2×3 的竖点，中距 6px，靠朝向那边整体偏 1px。不画嘴——20×28 画不下，画了就是噪点。

五、地形

关内局部（8 格宽）。岩壁边缘不齐、有抠块和受光短线，但仍是色块，没有纹理
#tile说明
0空不画，留透明
1实心砖 · 上表面2px 高光顶边，玩家站这面
2实心砖 · 下表面2px 高光底边，重力翻过来后玩家站这面
3实心砖 · 侧面无高光，洞壁
4实心砖 · 内部无高光，纯 #2E2530，用于填厚
5单向平台只画上半格，薄，下方透明
第 2 种（下表面）必须有，而且要和第 1 种一样明显。我们的玩法会让玩家倒着站天花板。天花板如果看起来跟内部砖一样平，玩家不知道自己能站——这是整套规格里唯一一个「不做就会让玩法失效」的点。

tileset 图布局：一张横排 PNG，每格 32×32，间距 0，不要留边距。Godot 建 TileSet 时填纹理区域 32×32、分离值全 0。

你交到哪为止：交这一张 tile_cave.png 就完事。不用摆关、不用建 TileSet、不用配碰撞——那些是策划和程序的活（见 03 第七节）。画完、按格切好、导出，地形这块你这边就结束了。
另外：Godot 4.7 里摆格子用的节点叫 TileMapLayer，不是 TileMap（已废弃）。照网上教程找 TileMap 找不到，不是你操作错了。

Q 版化的两条（几乎不花时间，但一眼能看出来）

  • 所有「外露的角」切 2px 斜角。直角看起来像工程图，切角看起来像 Q 版。只切玩家能看见的那个角（顶面两端、侧面上下端），被邻居挡住的角不用切。
  • 砖面只给 3 档明度，不加第二层纹理。

不要做的 Q 版化：不加圆点、不加笑脸、不在砖上画小石头。32px 一格塞任何装饰都会变成噪点，而且是两个人画风分叉最快的来源。

六、磁场（文档里叫「重力区」）与危险

先说命名，这条会直接打架。文档和群里习惯叫「重力区」，美术表现叫磁场，但代码和场景名一律用 gravity_zone。不要因为叫磁场就把代码名改了——CI 的提交 scope 是 gravity，已有脚本和场景都按这个走，改一次全队要跟着改。

磁场靠什么体现重力方向：靠里面悬浮的石粒。重力看不见，但石粒看得见——石粒朝哪边飘，重力就朝哪边。这是玩家读方向的主要依据，比箭头更直观，因为它就是「有东西在往那边掉」。箭头是第二重保险，保证三米外和投影仪上也一眼读得到。

半透明紫 = 场体（底下压着的墙还看得见），外框 = 2px 实线边界 + 四角加粗，小点 = 悬浮石粒（唯一会动的东西，朝箭头方向匀速漂），白箭头 = 方向，必须比所有石粒都亮。粒子的疏密是静态示意图，实际是连续漂移。

三层，只有石粒会动

层画法谁来画会动吗
场体ColorRect + #9B7FD4，不透明度 0.22–0.30程序不动
边界2px 实线 #9B7FD4 + 四角各一个 4×4 加粗角标程序不动
悬浮石粒每 32×32 格 3 颗、每个磁场最多 24 颗，每颗 2×2px，#FFF2E0 不透明度 0.55程序唯一会动的：沿箭头方向匀速漂 10 px/s，出界从反方向重入
方向箭头16×16，白芯 #F2F5FF + #D9C7FF 描边美术不动
为什么边界不用虚线：8 实 5 空的虚线在 640×360 上会被 3 倍整数缩放放大成一条条 24px 的长杠，看起来像在闪。改成 2px 实线 + 四角加粗，一样能说明「这是区域不是墙」，而且不闪。

为什么石粒不用贴图做：石粒必须连续漂移才读得出方向，3 帧贴图只能原地抖；而且每格都循环同一张图，会拼出肉眼可见的重复。石粒由程序用 ColorRect 生成，每颗相位错开。

三条硬限制

  1. 石粒必须比箭头暗。箭头是纯 #F2F5FF 实心加描边，石粒是 #FFF2E0 且 0.55 不透明度——一眼分得出主次。一样亮就是一片雪，方向反而读不出来。
  2. 每格 3 颗、每颗 2×2，但每个磁场总数封顶 24 颗。教学关那块磁场是 6×9 格，按 3 颗/格算会到 162 颗——那不是碎石，是沙尘暴，整块紫场会糊成一片。面积越大密度越低：小磁场（1–4 格）给 3 颗/格，大磁场按 24 颗摊开。
  3. 场体不透明度上限 0.30。超过之后玩家看不出这块紫里哪面墙能站，会直接走进坑里。

磁场这块，美术只交一个箭头

磁场其余三层全是程序画的，美术要交的只有一个朝上的箭头图标，16×16：三角底宽 12px、高 10px、杆宽 4px，垂直居中。太小在 3 倍放大后读不出方向，太大就盖住地形。

四向靠 90° 整数旋转（像素 90° 旋转无损，任意角度才糊），引擎 rotation_degrees 填 0 / 90 / 180 / 270。不要画四个。原来要求四个，现在只要一个，省三份活。

尖刺

32×32 一格，三角朝上，只画一个方向，布置时旋转。底部必须有基座（3–4px 深色条），否则看起来像浮在地面上。尖端加 #FFF2E0 白边，暗处才看得见轮廓。Q 版化：尖角切 1px，改「圆头三角」，一个像素的改动，气质差很多。

可动平台

单独一张 spr_platform.png，不许复用 tile。长得跟砖一样的话，玩家要等它开始动才知道这是平台，第一次踩上去必被甩走。

96×20 一张整图：3 格宽 × 16px 厚，底下留 4px 透明。长度和行程在 03 里都写死了，不用拼接。

  • 主体 #7C8FA6 钢蓝灰，顶面 2px 亮边 #B4C6D8，四角切 1px（跟砖同一个圆角规矩）
  • 顶面亮边上等距点 3 个 2×2 小方点，读起来像传送带——这是唯一提示「它会动」的地方
  • 不画箭头、不画链条、不加光效。这两个色比地形亮一档就成立，具体值自己调，只要不跟磁场的紫打架

九、四条禁令

  1. 加颜色要登记。新色接着 P13 排下去，写进第三节的表并注明用在哪，再过一次灰度判据。不登记就画，下一关没人知道那个色是什么。
  2. 不许画超出画布的内容。角色在 32×32 里画，超出的部分在 Godot 里会被切掉，看起来像 bug。
  3. 不许画「暗洞穴」。不画光源、不画阴影渐变、不画雾。纵深靠三档明度，不靠光。
  4. 除了磁场里的石粒，什么都不许动。全游戏唯一的动态是石粒漂移。不画背景飘尘、水滴、视差、环境动画。这不是省事——满屏都在动，玩家就分不清哪个动的东西在告诉他方向。

十、UI 与字体（11/2 用，但现在就要知道）

Godot 4 的内置字体不含中文字形。界面上写「继续」「通关」会显示成一排方框 □□□。这不是编码问题，不是你写错了，是那个字体文件里根本没有这些字。

所以现在就要准备：往仓库 Art/Fonts/ 放一个开源中文字体，然后在 项目设置 → GUI → Theme → Default Font 指定它。

字体体积说明
得意黑 Smiley Sans约 4 MB推荐。开源可商用，倾斜感强，做标题和 UI 都好看
思源黑体 SC Regular约 8 MB最稳，字形规矩，不出错

不要用系统字体路径（C:/Windows/Fonts/msyh.ttc 这种）。换一台机器就找不到，六个人里五个人的界面会变方框。

字号只允许四档：16 / 24 / 32 / 48。不用 12——中文在 12px 下笔画粘连认不出来。也不用 13、17、20 这种：非整数倍缩放会糊。

元素位置字号
关卡号（01 / 02…）左上角 (16, 12)16
中央提示（如「按住 ↓ 改变重力」）屏幕中央偏下24
死亡 / 通关大字屏幕正中48
按钮（开始、重玩、下一关）屏幕中央竖排16，按钮最小 120 × 32

不做的：血条（一碰就死，没有血量）、计时、小地图、设置菜单、音量滑块。一屏一关的游戏不需要这些。

十一、玩法与画面（不清楚从哪下手就先看这节）

前面十节讲规格，这节讲这游戏玩起来是什么样、画面里该有什么。

0. 重力是这游戏唯一的机制，不是机关之一

四关里每一关都有重力区，而且重力区是画面里最大的一块彩色区域——不是偶尔出现的道具。玩家所有判断都绕着一句话转：我现在被往哪个方向拽。尖刺、坑、平台、可动平台都只是这条规则的应用，它们本身不带新规则。

所以：紫色和那个白色箭头要画得足够清楚。它是整个游戏最重要的一个视觉符号，比角色还重要。角色画糊了玩家只是看不清自己，重力区画糊了玩家不知道该往哪走。

1. 玩家在一关里只做五件事

步玩家做什么你要画的东西
1按 ← → 在地上走地面砖，朝上那一面有 3px 高光边
2按空格跳上 2 格高的台阶台阶的侧壁 + 顶面
3从台阶顶跨过 4 格宽的坑坑里什么都不画，露出最暗的背景
4走进紫色区域，人被推向天花板半透明紫底 + 一个白色朝上箭头
5沿着天花板走到发光的门门洞；天花板内表面也要有一条 3px 高光边
全程只有两个动作：左右走、跳。没有攻击、没有道具、没有血量、没有敌人、没有计分。玩家只有一种死法：掉进坑里。所以也不需要「受伤」素材。

教学关的实际布局（这就是要画的第 0 关，20×11 格，一屏）：

青 = 玩家（Q 版 2 头身 20×28），紫 = 磁场（箭头朝上，石粒朝箭头方向漂），发光的框 = 终点，中间那片空洞就是坑。远景那两块暗色是从洞顶垂下来的岩体，不是平台，不能站。

2. 环境背景：地心洞穴的一条间隙

  • 这是一条纵向裂开的洞腔：上下都是岩壁，左右是两根岩柱，玩家在缝里往上走。没有天空、没有地平线、没有云、没有远景山。
  • 这个设定顺带把玩法解释了：上下都是石头，所以「倒着站天花板」不用额外跟玩家解释——他看得见头顶也是岩壁。
  • 洞腔内部填 #100D14，上面叠 #1C1720 的岩体剪影，从裂缝上下两端伸进来。边缘必须不规则，画成方框就变成房间，不是洞穴。
  • 纵深只有四档：#100D14 洞腔 → #1C1720 远景岩体 → #2E2530 砖块 → #4A3B45 + #6B5560 能站的表面。
  • 动态只有一个：磁场里漂移的石粒。其余一律静止——不画光源、光晕、阴影渐变、雾、熔岩、水滴、飘尘、背景视差。

3. 风格：像素 Q 版，一个方块最多三档色

判据值
1 个美术像素= 1 个屏幕像素，不做「先画大再缩小」
角色头身比2 头身：头 16×14 + 身 14×12 = 28 高，宽 20
角色脸两只 2×3 竖点眼睛，中距 6px，不画嘴
一个 32×32 方块内的明度最多 3 档
外露的角切 2px 斜角（Q 版最省钱的信号）
角色描边1px #3A8FA8 深青，不是黑
地形描边不描，靠明度差分离（1px 黑边在暗背景里等于消失）
半透明只允许两处：磁场场体 0.30 上限、石粒 0.55
动态只有磁场里的石粒会动，其余全静止

640×360 在 1080p 上是 3 倍整数放大，一个美术像素变成 3×3 的方块。细节多画一档，投到墙上就是一团噪点；两个人各画一套，风格也会分叉。

Q 版不等于加点细节。恰恰相反：Q 版是把形状做圆、比例拉成 2 头身、去掉一切装饰。20×28 这个尺寸上加细节，只会让它变成一团青色噪点，不会让它更可爱。
