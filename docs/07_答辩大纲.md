# 07 · 答辩与演示

> 交付形态是**发链接**（11/8 15:00 前到社团官网），不是现场跑 exe。路演是之后的环节，用来拉票。
> 所以真正的答辩不是你说得多好，是**评委点开链接那三分钟能不能看懂**。

## 三分钟演示脚本

| 时间 | 做什么 | 为什么 |
|---|---|---|
| 0:00–0:15 | 一句话说清是什么，**直接开玩** | 不要先讲架构和背景，注意力只有 30 秒 |
| 0:15–1:00 | 走完教学关：跳台阶 → 跨坑 → **走进重力区，人翻到天花板上** | 整个游戏最核心的一下，必须在第一分钟出现 |
| 1:00–2:00 | 第 2 关：地面全是尖刺，唯一活路是翻到天花板走 | 证明重力不是"换条路"，是"活命手段" |
| 2:00–2:40 | 第 3 关：连续翻转 + 可动平台 | 让人看到难度上限 |
| 2:40–3:00 | 通关画面 + 一句「下一版会做什么」 | 收尾要有完成感 |

**全程不解说操作。** 手已经在做，嘴再说一遍就慢了。只在转身那一下说"重力反了，跳变成往上蹬"。

## 答辩只讲三句

1. **「主题是重力。但这游戏里重力不由你控制——你只能适应它，靠走进不同的重力区来改变脚下的方向。」**
2. **「全场只有两个动词：走、跳。所有难度都在关卡设计上，不在操作上。」**
3. **「8 天里我们砍掉了钩索、boss、收集和剧情，只做四关。」**（显得有判断力，不是做不完）

## 被问「这跟 VVVVVV 有什么区别」

一定有人问，提前背好：

> VVVVVV 是**玩家按键翻转上下**，重力是玩家的一个技能。我们这版重力方向**由场景里的重力区决定**，玩家没有翻转键——他能做的只有"走到哪个区去"。
>
> 所以难点不是操作，是**看图和选路**：这一跳过去以后，落点是天花板还是地面，得在起跳前想清楚。这是解谜，不是动作。

## 被问「这跟重力什么关系」

**一句话**：「重力方向就是这游戏的关卡本身。」

追问就补 20 秒：

> 我们没把重力做成一个技能或者一个条，而是做成了**场地的属性**。同一段地形，重力朝上的时候走过去，朝右的时候就得跳过去。四关的难度全是靠"什么时候换方向"堆出来的。

## 被问「这代码是你写的吗」

- **可以说**：「这个模块我设计的、我验收的，编码时用了 AI 辅助。」
- **不要说**：「全是我自己写的。」一追问细节就反噬，比承认用了 AI 难看得多
- 硬要求：每人至少有一个**全程自己写、能在白板上复述**的模块
