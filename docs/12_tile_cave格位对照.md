> 记录 `Art/tiles/tile_cave.png` 是怎么来的、13 块各占哪一格。

## 一、文件是什么

| 项 | 值 |
|---|---|
| 路径 | `Art/tiles/tile_cave.png` |
| 尺寸 | **192 × 96**（6 列 × 3 行，每格 32×32） |
| 有效块数 | **13 块**（第 1 行 1 块 + 第 2 / 3 行各 6 块） |
| 背景 | 透明 |
| 间距 | **0**（每格紧贴，TileSet 才能切） |

## 二、格位

```
列:      1     2     3     4     5     6
行1:    砖①   空    空    空    空    空
行2:    砖2    砖3   砖4   砖5   砖6   砖7
行3:    砖8    砖9   砖10  砖11  砖12  砖13
```

编号按「从左到右、从上到下」数。**空格子不使用**——配 TileSet 时那几格留空就行。

## 三、来源与做过的处理

- 原稿：**陶毅** 给的 `tile.png`（360×240，6 列 × 3 行的砖块矩阵，砖与砖之间有 8–10px 间隙）
- **只做了裁切和重排**：按探测出的坐标把每块裁成 32×32，再贴紧排进 192×96
- **像素内容未做任何修改**（没重画、没缩放、没改色、没描边）
- 原稿里的对应坐标（供核对）：

| 行 | 各块的 x 起点 | y 起点 |
|---|---|---|
| 行 1 | 202 | 66 |
| 行 2 | 80 / 121 / 162 / 202 / 241 / 282 | 104 |
| 行 3 | 80 / 121 / 162 / 202 / 241 / 281 | 144 |
