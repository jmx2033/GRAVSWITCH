# 像素美术规格

> 给美术 A（风扇）、美术 B（三尺）
> 这份看完就能开工。尺寸、色值、命名、导出，全部照抄，不要自己发挥。

## 一、三句话定调

主题是**地心间隙里的山洞**。这个主题成立，而且是 8 天里最省钱的选择。但有三条必须先说清：

**1. 做「亮的洞穴」，不做「暗的洞穴」。**
洞穴天然让人想到黑暗，但 2D 像素做光照（`Light2D`、`CanvasModulate`、点光源）成本极高，而且会直接破坏玩法——玩家必须一眼看清重力区往哪个方向。所以用**色调分层**造纵深：近景亮、中景中、远景暗。不画光。

**2. 做「色块洞穴」，不做「写实岩石」。**
岩石纹理是最容易画成墙纸的东西：拼十格就看出重复。只用 4–6 种 tile，靠**轮廓 + 三档明度**区分，不靠纹理细节。这是省钱也是好看。

**3. 颜色只编码三件事，不编码第四件。**
紫 = 重力区，橙 = 危险，青 = 你。**方向靠箭头，不靠颜色。** 四向各配一色看起来聪明，实际是让玩家记四个含义、让美术多画四套素材。

## 二、画布与尺寸

| 项 | 值 | 说明 |
|---|---|---|
| 逻辑分辨率 | **640 × 360** | 一屏 20 × 11 格 |
| tile 尺寸 | **32 × 32 px** | 所有关卡、机关、地形都按这个拼 |
| 角色画布 | **32 × 32 px** | 方便对齐网格和在 Godot 里切帧 |
| 角色实际像素 | **20 × 28 px** | 画在 32×32 画布里，水平居中、底部贴齐（上方留 4px 余量放头顶/跳跃拉伸） |
| 角色碰撞盒 | 20 × 28 px | 与角色实际像素区重合，不要画超出画布 |
| 一关尺寸 | 20 × 11 格 = 640 × 352 px | 下方留 8px 给地板厚度余量 |

**角色在屏幕上有多大**：1080p 全屏是 3 倍整数缩放，20 像素宽会变成 60 像素。正常人一眼能看清手脚和朝向，不需要画到 48px。

## 三、调色板（12 个起始色，分「锁死」和「可调」两层）

**不是全锁的。** 真正不能动的是 5 个编码玩法信息的色，其余 7 个美术自己调，改完在表里登记新值就行。

### 锁死（5 个，动之前群里说一声）

动这 5 个等于改规则，玩家会误读。

| 编号 | 色值 | 用途 | 为什么不能动 |
|---|---|---|---|
| P03 | `#2E2530` | 中景岩壁 / 地形内部 | 三档明度里的一档，动了纵深关系就散 |
| P04 | `#4A3B45` | 近景岩壁（能站的地面与天花板） | 同上，而且这是玩家判断「能不能站」的依据 |
| P06 | `#7FE8FF` | 玩家 | 玩家是全场唯一的青，混了就找不到自己 |
| P08 | `#9B7FD4` | 重力区 | 玩家要一眼认出「这里会改重力」 |
| P10 | `#FF8A3D` | 危险（尖刺） | 橙只给「会死的东西」，别处不许用橙 |

### 可调（7 个，自己定，改完在表里写新值）

| 编号 | 起始值 | 用途 |
|---|---|---|
| P01 | `#100D14` | 最远背景（暖紫黑） |
| P02 | `#1C1720` | 远景岩层 |
| P05 | `#6B5560` | 岩壁受光面与边缘高光 |
| P07 | `#3A8FA8` | 玩家暗部与描边 |
| P09 | `#D9C7FF` | 重力区箭头与描边 |
| P11 | `#FFF2E0` | 危险的高光边、UI 文字 |
| P12 | `#F2F5FF` | 纯白备用（高光点、粒子） |

### 加色规则：可以加，但要过一条判据

新色接着排（P13、P14…），写进上表并注明用在哪，然后过这一条：

> **把画面转成灰度，玩家、重力区、尖刺三样必须还能分开。** 分得开就加，分不开就不许加。

这条不是审美要求，是玩法要求：玩家靠颜色判断「这里有重力」「这个会死」。灰度分不开，色盲玩家分不出，路演投影仪上也会糊成一片。

**底色为什么从 `#0B0E14` 改成 `#100D14`**：原来那个是冷蓝黑，配太空题材用的；现在是地心洞穴，岩壁是暖紫棕，冷底会把画面压灰，而且玩家是青色，跟冷底同色系会融进去。换成暖紫黑之后，青色玩家在暗处是跳出来的。

## 四、角色（`spr_player.png`）

**动画帧数按这个来，不要多画。**

| 动作 | 帧数 | 优先级 |
|---|---|---|
| idle（站立） | 2 | 必须有 |
| run（跑） | **4** | 必须有，这是玩家看得最多的一帧 |
| jump（上升） | 1 | 必须有 |
| fall（下落） | 1 | 必须有 |
| die（死亡） | 3 | 有剩余时间再画，没有就用闪白代替 |

共 11 帧。**run 的 4 帧是重点**，其他都可以糙。

**sprite sheet 布局**：所有帧横排成一行，每帧占 32×32 的格子，从左到右按上表顺序排列。不要做成一张张散图，Godot 里一个 `Sprite2D` 填 `hframes = 11` 就能切。

**朝向**：只画朝右，朝左在 Godot 里用 `flip_h` 翻转。不要画两套。

**描边**：外轮廓必须有 1px 深色描边（`P07`），否则在暗背景里会融进去。

## 五、地形（`tile_cave.png`）

**只做 6 种，多一种都不要。**

| 序号 | tile | 说明 |
|---|---|---|
| 0 | 空 | 不画，留空 |
| 1 | 实心砖 · 上表面 | 有 P05 高光顶边，玩家站这面 |
| 2 | 实心砖 · 下表面 | 有 P05 高光底边（重力翻过来后玩家站这面） |
| 3 | 实心砖 · 左右侧面 | 洞壁 |
| 4 | 实心砖 · 内部 | 无高光，纯 P04，用于填厚 |
| 5 | 单向平台 | 比砖薄，只画上半格，下方留透明 |

**关键一条**：第 2 种（下表面）必须有，而且要和第 1 种一样明显。**我们的玩法会让玩家倒着站天花板**，如果天花板看起来跟内部砖一样平，玩家不知道自己能站。

**tileset 图布局**：一张横排 PNG，每格 32×32，**间距 0，不要留边距**。Godot 的 TileSet 建的时候填 `texture_region_size = 32×32`、分离值都给 0。

## 六、重力区与危险

**重力区不画纹理。** 它是半透明色块 + 白色箭头，在 Godot 里用 `ColorRect` + `P08` 透明度 0.35 就能做，不需要图。

美术要交的是**四种箭头图标**（每个 16×16 或 24×24）：↑ → ↓ ←，颜色 `P09`。一张横排 sheet 即可。

**尖刺**（`spr_spike.png`）：32×32 一格，三角朝向由摆放旋转解决，只画朝上一个方向。底部与地面接触处加 `P11` 白边提亮，否则在 `P04` 地面上看不出边缘。

**可动平台**：直接复用 tile 的第 1 种和 第 2 种，不需要单独素材。

## 七、文件命名与导出

| 前缀 | 用于 | 示例 |
|---|---|---|
| `spr_` | 有动画的东西 | `spr_player.png`、`spr_spike.png` |
| `tile_` | TileSet 图 | `tile_cave.png` |
| `bg_` | 背景（可平铺） | `bg_cave.png` |
| `ui_` | 界面元素 | `ui_button.png` |
| `icon_` | 图标 | `icon_arrow_up.png` |

全小写下划线，不加版本号（`_v2`、`_final`、`_new` 一律不许），改了就覆盖，Git 里有历史。

**导出设置**：

- 格式 **PNG**，透明背景，不要 JPG（JPG 会把边缘糊成噪点）
- **不要缩放**，按 1:1 原始像素导出
- 不要在导出时加锐化、加滤镜、加抗锯齿
- 透明区域必须是真透明，不要填白色

## 九、三条禁令

1. **加颜色要登记。** 新色接着 P13 排下去，写进第三节的表并注明用在哪，再过一次灰度判据。不登记就画，下一关没人知道那个色是什么。
2. **不许画超出画布的内容。** 角色在 32×32 里画，超出部分在 Godot 里会被切掉，看起来像 bug。
3. **不许画「暗洞穴」。** 不画光源、不画阴影渐变、不画雾气。纵深靠三档明度（`P02` / `P03` / `P04`），不靠光。

## 十、UI 与字体（11/2 才做，但现在必须知道）

**Godot 4 内置字体不含中文字形。** 界面上写「继续」「通关」会显示成一排方框（□□□）。这不是编码问题，不是你写错了，是那个字体文件里根本没有这些字。

所以现在就要准备：往仓库 `Art/Fonts/` 放一个开源中文字体，然后在 `项目设置 → GUI → Theme → Default Font` 指定它。

| 字体 | 体积 | 说明 |
|---|---|---|
| **得意黑 Smiley Sans** | 约 4 MB | 推荐。开源可商用，倾斜感强，做标题和 UI 都好看 |
| 思源黑体 SC Regular | 约 8 MB | 最稳，字形规矩，不出错 |

**不要用系统字体路径**（`C:/Windows/Fonts/msyh.ttc` 这种）。换一台机器就找不到，六个人里五个人的界面会变方框。

**字号只允许四档**：16 / 24 / 32 / 48。

不用 12：中文在 12px 下笔画粘连，认不出来。也不用 13、17、20 这种：640×360 的游戏做非整数倍缩放，字会糊。

**HUD 布局（都在 640×360 内）**：

| 元素 | 位置 | 字号 |
|---|---|---|
| 关卡号（`01` / `02`…） | 左上角 (16, 12) | 16 |
| 中央提示（如「按住 ↓ 改变重力」） | 屏幕中央偏下 | 24 |
| 死亡 / 通关大字 | 屏幕正中 | 48 |
| 按钮（开始、重玩、下一关） | 屏幕中央竖排 | 16，按钮最小 120 × 32 |

**不做的东西**：血条（我们是一碰就死，没有血量）、计时、小地图、设置菜单、音量滑块。一屏一关的游戏不需要这些，做了就是浪费 11/1 那个唯一整天。
