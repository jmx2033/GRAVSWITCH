### 11/7 · 挑战关专属能力：空中主动改重力（已实现）

**来由**：陶毅 11/7 提议「方向键 + 空格改变重力方向，落地前不能再改」，
目的是让重力从"地形机关"变成"操作的一部分"。负责人决定**先只在挑战关 0 独立生效**，不动四关。

**操作规则**（陶毅照这个测）：

| 状态 | 按空格 | 说明 |
|---|---|---|
| **站在地上** | 跳跃 | 地面按空格永远是跳，跑跳手感不变 |
| **在空中 + 按住方向键** | **把重力改成该方向** | 一次滞空只能用一次 |
| **在空中 + 没按方向** | 跳预输入（不变） | 保留土狼时间 |

**四个方向都可用**（11/7 加 `move_up` / `move_down`）：

| 按住 | 重力变成 |
|---|---|
| `←` / `A` | 朝左 |
| `→` / `D` | 朝右 |
| `↑` / `W` | 朝上 |
| `↓` / `S` | 朝下 |

- **垂直优先于水平**：同时按住 `→` 和 `↓` 时按空格，取**朝下**。
  因为水平键是跑动时一直按着的，若水平优先就会在跑跳时误触发改重力
- **落地即刷新**：脚一沾地就重新获得一次改重力的机会
- **重力区优先级最高**：区里改重力不生效；**出区后**玩家设定的方向继续生效

**为了加 `↑` `↓`，`project.godot` 新增了两个 action**（`move_up` / `move_down`，
键位 `W`/`S` + `↑`/`↓`）。这是对 `AGENTS.md`「输入只有三个动词」的一处**例外**，
范围和理由已写进 `AGENTS.md` 的输入章节：

- 两个 action **只有挑战关用**，四关的行为与之前完全一致
- 能力由关卡授权，不是全局开关：`challenge_level.gd` 调 `player.enable_gravity_shift()` 才打开

**为什么不给四关开**：四关的谜题设计**全部依赖**「重力只能由重力区改变」。
比如教学关右侧那个「10 格宽的坑，跳不过去，只能靠区」，玩家一旦能自己改重力就直接飞过去了，
四关的难度与谜题会同时失效。

**实现**（都在 `player.gd`，默认关闭所以四关不受影响）：

- 开关：`_gravity_shift_enabled`，由 `challenge_level.gd` 在 `_ready` 里调
  `player.enable_gravity_shift()` 打开
- 状态：`_shifted_gravity`（玩家设定的方向，ZERO = 没改过）、
  `_gravity_shift_used`（本次滞空是否用过，落地清零）
- 方向读取：`_shift_direction_from_input()`，先看 `move_up`/`move_down` 再看左右
- 重力汇总多了一条来源：没有重力区时用 `_shifted_gravity`，有区时区优先
- 转向动画、音效、`up_direction` 全部复用现有重力区那套逻辑，没有另写一份
