· 现状：一个能在浏览器里直接跑起来的可玩原型，不是 PPT。

▍在做什么
2D 俯视角动作生存 + 三选一构筑。核心不是数值堆叠，是"蓄力—闪切"：
按住蓄力，世界慢下来；松手，沿鼠标方向切出一道刀光，穿过敌群。
说白了，这是个靠"切"吃饭的游戏。

▍为什么现在最缺音效
这个类型里，声音不是背景，是打击感的另一半。我们的问题很具体：
· 蓄力分三段，每一段都要能被"听"出来——玩家闭眼也该知道自己在第几段；
· 一刀切中 3 个和切中 8 个，听感必须不一样，但绝对不能糊；
· 世界减速的时候，声音也得跟着变慢，而不是继续按原速播。
现在这套声音是程序用 Web Audio 临时合成的：方向对，但离"好听"还很远。
所以你进来不是从零搭系统，是在一个已经能出声的框架上，把它做成真的。

▍希望你
· 会音效设计 / 合成；或者愿意用 Web Audio、免费素材库自己捏也行；
· 接受先做到"能用"，再一起迭代到"好听"；
· 每周能稳定投入几个小时，做久一点——不想做一个月就散。

▍位置
上限 6 人，现在 3 人，你进来是第 4 位。
另外还剩 2 个位置：如果你擅长 Unity 实机移植，或者关卡 / 节奏设计，也欢迎聊。

感兴趣私我，先给你听 15 秒现在这版（临时音），你大概就知道还缺什么了。
```

## 写的时候做了什么判断（给发布者看，不要贴出去）

1. **不写"我们很缺人"，写"这里有一块具体的活"。** 音效最怕的是进队之后无事可做、或者只被要求"配几段 BGM"。所以三行需求（三段可辨、叠层不糊、减速跟随）全部写成了**可验证的声音问题**，让对方一眼看出这东西有设计空间。

2. **把"现有音效是程序临时合成的"当成卖点而不是短板。** 对音效来说，最劝退的是"一片空白、要从零搭"，最吸引人的是"框架有了，就等你来做"。这句话同时建立了信任（我们诚实）和安全感（你不用负责架构）。

3. **队友那一栏不放"获奖 / 热情 / 上进"。** 放的是可核对的东西：40+ PR、云端部署、LLM 机器人、C++ 底子、玩过大量解谜与 2D 平台。组队平台上大家都会写"热爱游戏"，能区分人的是"他做过什么，做到什么程度"。

4. **没有写"美术很强"来抬高身价。** 目前的定位是 2D 美术 + 想学程序，诚实标注比夸大更能留住人——音效进来后要长期合作，前期吹过头，第三周就会互相失望。

5. **留了 2 个位置的说明，但把音效放在第一位。** 上限 6 人，现在 3 人，主目标仍是音效；顺带提 Unity 移植，是因为这确实是第二块短板（引擎经验都还在学的阶段），但不抢主次。

6. **项目名可以直接写。** 之前"别先丢项目"的建议针对的是社团群刷屏场景；这里是组队平台，对方本来就会点进项目介绍看，藏名字反而显得可疑。

## 发布前需要处理的一处矛盾（建议）

队友的项目介绍里，对《闪切协议》的描述是「2D 俯视角动作生存 + 三选一构筑 + **轻量局外养成**」。

但按 v0.3 设计文档，**阶段 0 明确不做局外成长**，而且要等 3 分钟沙盒全部硬门槛通过之后才评审后续内容。

风险不在于"写了会怎样"，而在于：**音效这类长期岗位会关心"这项目到底有多大、能做多久"**。如果对方带着"有局外养成、内容量不小"的预期进来，发现第一阶段只有 6 张卡、1 张地图、3 分钟，容易觉得被画了饼。

建议二选一：
- **改介绍**：把「轻量局外养成」改成「轻量局外解锁（阶段 2 后评审）」，或在项目介绍里补一句"当前阶段先做 3 分钟手感沙盒"；
- **不改介绍，但在私聊里先讲清**：第一阶段目标就是验证手感，做完再谈扩展。

## 收人判断（2026-10-27，当前 5 人）

现状：策划 1（马权）、程序 2（落叶归粥 + 1）、美术 2（_风扇、三尺）。上限 6 人，**只剩 1 个位置**。

新申请人：叶一谦（创游工坊 2026 届），自报「策划 / 程序 / UI」，问"还招程序或策划吗"。

**结论：阶段 0 期间不收。这 1 个位置留给音效。**

理由：

1. **名额是唯一稀缺资源。** 5→6 就封顶，收了他，之后再来一个音效就没位置了。现在音效是 0 人且是硬缺口，把一个位置花在"已有 2 人 + 已有 1 人"的岗位上，等于把最缺的东西换成了最不缺的东西。
2. **阶段 0 的瓶颈不是人手。** demo 已在浏览器跑通、自动回归通过，剩下的是修 2 个缺陷、5 人试玩、A/B 蓄力、目标设备性能——**实际工作量约 1 人 2–3 天，其余时间全在等人来试玩**。5 个人分这些活，是人手过剩。
3. **他的岗位在阶段 0 全冗余。** 策划已有（且阶段 0 的决策只有"改不改参数"）；程序已有 2 人，而单文件 demo 同时两人改会互相踩；UI 在这个几何体极简风格里需求量接近零。

**但他是个好资源，别直接拒掉：转成试玩者。** 目前"5 人试玩"只完成了 1 人（主程），真正的缺口在这里。

### 可直接回复的话术

```

### 什么时候该收

- 阶段 0 硬门槛过完之后（进入阶段 1 垂直切片），工作量结构会变：远程敌人、8 张卡、折线/连锁都在程序侧，**那时缺的是程序**，不是策划和 UI。
- 到时候优先找他，且要先给一个带交付物的小任务（例如独立做一个技能原型），不接受"先拉进群再说"。
