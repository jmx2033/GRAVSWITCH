## 一、为什么不用现成素材

| 方案 | 结论 |
|---|---|
| 网上下载素材 | ❌ `AGENTS.md` 禁止引入第三方资源；且现成素材很难精确满足「0.2~0.3 秒、无混响、特定音量」这类量化要求 |
| AI 音乐生成工具 | ❌ 输出不可控（每次结果音色漂移），且多为 mp3/44.1kHz，要二次转码 |
| **numpy 数学合成** | ✅ 参数完全可控、零版权风险、直接输出 48kHz/16-bit |

代价是：**物理参数能精确控制，但"听起来对不对"只能靠耳朵**。所以调音色是"给出物理原因 → 试听 → 再修"的循环，不是随机试参数。

## 二、玉音的核心：非谐波泛音 + 独立衰减

这两点是"像乐器"与"像合成音"的分界线。

### 2.1 泛音比必须是非整数

| 方案 | 泛音比 | 听感 |
|---|---|---|
| 整数谐波 | `1 : 2 : 3 : 4` | 钢琴 / 电子琴，规整但"电子味" |
| **玉石模态** | `1 : 2.20 : 3.70 : 6.10` | 玉磬、钟、玻璃——稀疏、略有金属感但不刺耳 |

玉石、钟、玻璃这类**自由振动体**的模态比不是整数。用整数比怎么调都摆脱不掉电子琴味——这是早期"像电铃"的根本原因。

### 2.2 每个泛音有自己的衰减时间

```python
partials = [
    (1.00, 1.00, 0.050),   # 基音：留得最久
    (2.20, 0.42, 0.036),   # 第二泛音：玻璃亮感
    (3.70, 0.22, 0.028),   # 第三泛音：清脆的"叮"
    (6.10, 0.10, 0.018),   # 极轻的高"叮"，散得最快
]
sig += amp * np.sin(ratio * phase) * np.exp(-t / tau_i)
```

**高频散得快、低频留得久**，这是真实共鸣体的物理行为。只用一个统一包络套所有谐波，听起来就是"合成音"而不是"乐器"。

### 2.3 起音：1ms 斜坡 + 极短玻璃质"叩"

```python
sig += 0.14 * np.sin(5.0 * phase) * np.exp(-t / 0.0040)   # 叩击瞬态，4ms 内散尽
sig *= np.clip(t / 0.0010, 0.0, 1.0)                       # 1ms 起音斜坡
```

斜坡保证"按下去就响"（responsive）而不是渐入；叩击瞬态给敲击感但绝不铺宽带白噪（那样会有刮擦感）。

## 三、九个音效的实际参数

全部归一化到 **峰值 0.63（≈ -4dB）**，不抢戏、不削波。

| 文件 | 时长 | 基频 | 关键设计 |
|---|---|---|---|
| `sfx_walk_1..4` | 250ms | 420 / 450 / 480 / 510 Hz | 玉珠敲抛光石面。**四条同款微差**，只有基频不同 |
| `sfx_jump_1` | 220ms | 1000 Hz | `pitch_rise=0.08`，前 30ms **上扬** 8% → "离开地面" |
| `sfx_land` | 280ms | 600 Hz | 换 `heavy` 泛音组 + `tau_scale` 略大 = 更厚、余韵更足 |
| `sfx_flip` | 300ms | 850 → 600 Hz | **双珠先后敲**（0ms / 80ms），下沉二音 |
| `sfx_die` | 700ms | 700 Hz | 初击 + **6 块碎片**在 30~185ms 间散开、各自音高不同 |
| `sfx_win` | 800ms | 700 Hz 起 | **五声音阶上行**（700/816/940/1052/1219），收在高音 |

### 实测频谱（用 FFT 验证，不是估计）

```
文件           时长   低(<800) 中(0.8-4k) 高(>4k)   主要峰频
sfx_walk_1    250ms     59%      41%       0%      420, 924
sfx_jump_1    220ms      3%      87%      10%      1036, 2072（上扬前）
sfx_land      280ms     62%      38%       0%      596, 1257
sfx_flip      300ms     32%      63%       5%      600, 560
sfx_die       700ms     28%      61%      11%      637
sfx_win       800ms     12%      77%      11%      671
```

能量的分布规律很清晰，和功能一一对应：

- **走 / 落 → 低频重**（57~62%）：踩地要有分量
- **跳 → 中频重**（87%）、低频近乎没有（3%）：离开地面，轻
- **翻转 / 死亡 / 通关 → 中频为主**：有旋律感，不是打击
- **高频全都 ≤11%**：这是"不刺耳"的定量保证

## 四、踩过的坑

### 坑 1：整数谐波 → 怎么调都像电子琴

早期用 `1 : 2 : 3` 泛音比，反复出现"电铃""太脆""太闷"的反馈。换非整数比后一次就接近了。

### 坑 2：分音幅度压太狠 → 听起来像单调电子音

试过 `amp_pow = 2.2`（第二泛音只剩 0.22 再叠加衰减差），FFT 显示基频独占 `1.00`、第二泛音只有 `0.07`——那听着就是单一频率。

**放宽到 `amp_pow ≈ 0.9~1.0` 后**，第二泛音升到 `0.21`、第三泛音 `0.08`，三个分音都听得见，才有"多分音共鸣"的玉磬感。

> 判据：拿 FFT 看，如果除基音外其它泛音相对幅度都低于 0.1，那就是电子音，不是玉。

### 坑 3：尾韵太长 → 拖沓；太短 → 没有玉味

`tau_base` 决定尾韵。实测：

| tau_base | -40dB 衰减 | 听感 |
|---|---|---|
| 0.055 | ~207ms | 接近整个时长，拖沓 |
| 0.050（走用） | 适中 | 玉珠清脆 |
| 0.018（最高泛音） | 极短 | 高"叮"一闪而逝 |

**不同泛音用不同的 tau** 才能既有清亮又干净，不是靠一个总包络折中。

### 坑 4：末端硬剪出"咔"

衰减还没散尽就截断，会在尾部产生跳变（听起来像"咔"）。

修法：给长音效**更长的线性淡出**：
- 走音：2ms（0.25s 处已近乎无声）
- 跳音：25ms
- 落地：40ms（280ms 处仍有约 -39dB 残余）
- 翻转：30ms

## 五、播放逻辑（`Scripts/player/player_sfx.gd`）

| 项 | 值 | 说明 |
|---|---|---|
| 走音间隔 | `0.4s` | 音效本身 0.25s，留重叠让脚步连贯 |
| 走音变体 | 4 个，2 个播放器交替 | 允许重叠；随机选但不与上次重复 |
| 落地音量 | 按冲击速度映射 1.0→2.0 倍 | `JUMP_SPEED` 对应 1.0，自由落体 288px（≈1018px/s）对应 2.0 |
| 落地延迟 | `0.1s` | 留空白，避免和紧邻的起跳音重叠 |
| 落地音量偏移 | `-6dB` | 整体调小，落地不该比跳抢 |
| 落地最小速度 | `50px/s` | 低于此不播，避免贴地抖动误触 |

## 六、改音色时的自查清单

1. **FFT 看泛音**：除基音外其它峰相对幅度是否 ≥0.1？全低于 0.1 就是电子音
2. **高频占比 ≤15%**：超过容易刺耳
3. **听"拖沓感"**：阶梯电平表看 -40dB 衰减时间，超过总时长的 70% 就会拖
4. **听尾部有没有"咔"**：残量大的音效必须给长淡出
5. **四条走音要"同款微差"**：音色一致、只有音高差 3~6%
6. **跳跃上行 / 翻转下行**：这是玩家区分"我跳了"和"世界翻了"的唯一听觉线索，方向不能弄反

## 七、以后要加音效的话

复用 `jade_note()` 这个函数，把参数传进去即可，**不要另写一套合成逻辑**——那样各个音效的"乐器感"会不一致。

```python
jade_note(f_pitch, dur, amp=0.63,
          tau_scale=1.0,        # >1 更厚更慢（大块玉石）
          pitch_rise=0.08,      # 上扬比例，跳跃类用
          partials=None)        # 默认玉珠组；落地类传 heavy 组
```

新增音效的检查项同第六节。
