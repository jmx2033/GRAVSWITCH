# GRAVSWITCH（重力开关）

> 2D 像素平台跳跃解谜。你走在一间会改变重力的房子里——走进哪个区，脚下就朝哪个方向。
> **你能做的只有走和跳。重力不由你控制，你只能适应它。**
> 四关，一屏一关，全程靠"往哪跳"。

## 为什么统一 GDScript

| 原因 | 具体 |
|---|---|
| **版本必须统一** | C# 要用 Mono 版编辑器。**标准版打开带 `.cs` 的工程会直接报"缺少 C# 支持"，工程跑不起来。** 所以不存在"某人写 C#、其他人写 GDScript"，只能全队一个语言 |
| 装机成本 | 走 C# 要六个人今晚全部重装（Mono 编辑器 + .NET 8 SDK + 另一套导出模板），一个人漏装就出不了包 |
| 网页版 | C# 的 Web 导出基本不可用，而网页版是路演投票要用的（评委点开就能玩） |
| 学习成本低 | GDScript 语法接近 Python；而且 Godot 的节点 / 场景 / signal 这套，用 C# 也一样要从头学 |

> 会 C# 的看 `docs/09_CSharp到GDScript速查.md`，一页。

## 装什么（六个人一模一样）

| 必装 | 验收 |
|---|---|
| **Godot `4.7.2-stable`** —— 用群文件里那一个 exe，**不要自己去官网下**（官网可能已经是 4.8，`.tscn` 有版本标记，4.8 存过的 4.7 打不开） | 打开后 `帮助 > 关于` 版本号六人一字不差 |
| **导出模板** —— 编辑器 → 管理导出模板 → 下载 4.7.2，**Windows 与 Web 各一份**（约 900 MB） | 能成功导出一次空包 |
| **Git for Windows ≥ 2.40** | `git --version` ≥ 2.40 |
| **GitHub 账号**（一人一个）+ 已被加成 collaborator | 能 `git push` |
| **SSH 密钥**（贴到自己的 GitHub） | `ssh -T git@github.com` 返回 `Hi <你自己的账号名>!` |

**不需要装**：Unity、Unity Hub、Unity ID、Visual Studio、VS Build Tools、.NET SDK、任何插件。

> 首次使用先配 Git：`docs/工程规范.md` §5.0。

## 怎么跑起来

1. 装好 Godot 与 Git，配完 `git config`（`docs/工程规范.md` §5.0）
2. **配 SSH 并以 SSH 地址克隆**：`git clone git@github.com:jmx2033/GRAVSWITCH.git`
   路径用纯英文、不要中文和空格（推荐 `D:\git\GRAVSWITCH`）
3. **不要把项目放在 OneDrive / 坚果云 / 百度网盘同步目录里**——云同步会和 `.godot/` 打架
4. 双击 `project.godot`，Godot 会打开工程
5. F5 运行

> 工程由珈百璃先建好推上来，其他人**等推上去再 clone**。各自先 clone 会生成不同的 `.godot/`，之后很麻烦。

## 怎么出包

- **先确认导出模板已下载**（这是第一次出包唯一会卡住的地方，报错长这样："找不到导出模板"）
- Windows：`项目 > 导出 > Windows Desktop > 导出项目`，输出到 `build/win/`
- 拷贝给别人时**整个目录一起打包**，只发 exe 会缺 `pck`
- 出包用普通终端，不要在受限沙箱里跑
