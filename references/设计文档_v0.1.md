| 核心机制 | 手动瞄准、蓄力、闪烁位移、路径范围切割 | 已确认 |
| 美术题材 | 几何体角色与敌人、极简赛博朋克 | 已确认 |

| 联网与付费 | 单机；原型不含联网、广告和内购 | 暂定 |

### 1.2 一句话体验承诺

在几何敌潮中预判包围路线，以减速蓄力换取一次穿越敌阵的高精度闪切，再通过带取舍的三选一强化，形成自己的切割协议。【已确认方向】

### 1.3 核心设计假设

1. 手动瞄准与蓄力减速，能让玩家感到“这次多杀来自我的判断”，而非自动攻击的随机结果。【待试玩验证】
2. 长度、宽度、速度之间的负向取舍，能形成可辨认且可混合的构筑，而不是只追求单一数值最大的升级。【待试玩验证】
3. 短促顿帧、路径残光、几何碎裂、分层音效与连杀递增反馈，能在不遮挡敌方预警的前提下提供足够爽感。【待试玩验证】

### 1.4 设计支柱

- **切割由玩家负责**：瞄准、蓄力时机与路径选择均由玩家决定。
- **强化必须改变操作感受**：升级不仅增加伤害，也改变闪切距离、覆盖形状、释放节奏或风险。
- **强反馈不妨碍读招**：高威胁攻击的预警始终位于装饰特效之上。
- **先证明一次闪切好玩，再扩充内容数量**。

## 2. 核心循环与单局结构

### 2.1 秒级核心循环

**WASD 移动聚怪 → 鼠标瞄准 → 按住左键蓄力并观察切割预览 → 松开左键闪烁，切割整条路径 → 敌人断裂并掉落经验 → 吸取经验、升级三选一 → 根据新形状与节奏规划下一刀**

| 环节 | 玩家决策 | 即时反馈 | 代价或风险 |
|---|---|---|---|
| 移动 | 聚怪、躲避、寻找可穿越阵型 | 玩家几何体转向、位置变化 | 被包围或接触受伤 |
| 蓄力 | 等待更高收益或提前释放保命 | 世界减速、预览增宽或伸长、升调音效 | 蓄力期间仍可受伤 |
| 闪切 | 选择路径与落点，追求多目标命中 | 瞬移、残光、命中停顿、碎裂与音效 | 冷却、落点风险、蓄力时间成本 |
| 奖励 | 继续收割或拾取经验 | 经验吸附、连杀计数、升级提示 | 为拾取经验进入危险区域 |
| 构筑 | 从三项强化中选择一项 | 切割预览和实际参数立即变化 | 部分强化附带负向属性 |

### 2.2 十分钟节奏【暂定】

| 时间 | 内容 | 设计目的 |
|---|---|---|
| 0:00–1:00 | 基础追击敌人，首次升级在 20–30 秒内出现 | 无文字墙地学会移动、瞄准、释放 |
| 1:00–3:00 | 加入高生命阻挡敌人，形成基础构筑方向 | 让玩家感知宽度与长度差异 |
| 3:00–5:00 | 加入远程敌人与精英，要求调整落点 | 防止只沿同一方向反复闪切 |
| 5:00–7:30 | 加入预警冲锋或爆破敌人，提高阵型密度 | 检验减速蓄力下的风险判断 |
| 7:30–9:00 | 高密度混合敌潮，构筑进入成型阶段 | 提供连穿与清屏爽点 |
| 9:00–10:00 | 首领战 | 验证单体输出、预警阅读和闪切落点 |
| 10:00 | 协议崩溃，未击败首领则本局失败 | 控制单局时长 |

### 2.3 胜负条件

- **胜利**：10:00 前击败首领，显示存活时间、最高连穿、总击杀、所选强化和获得资源。
- **失败**：生命降至 0，或 10:00 时首领仍存活。
- **暂停**：打开暂停菜单时冻结战斗与计时；升级三选一时冻结战斗。
- 胜负界面均提供“使用同一初始协议重开”和“返回协议终端”。【暂定】

## 3. 玩家角色与操作

### 3.1 角色形象

- 玩家为青色空心三角楔体，尖端指示瞄准方向。【暂定】
- 核心亮点表示当前生命与蓄力状态；不依赖复杂骨骼或手绘动画。
- 角色与敌人的形状、颜色和轮廓同时区分，避免仅用颜色表达威胁。

### 3.2 输入映射【暂定】

| 输入 | 功能 | 成功反馈 | 失败或不可用时反馈 |
|---|---|---|---|
| WASD | 八方向移动，斜向速度归一化 | 角色移动，轻微拖尾 | 到达场地边界时停止并出现细线阻尼 |
| 鼠标移动 | 瞄准 | 角色尖端和预览方向跟随 | 无 |
| 按住鼠标左键 | 进入并维持蓄力 | 时间平滑减速、预览展开、升调音效 | 冷却期间不进入蓄力，显示冷却环 |
| 松开鼠标左键 | 按当前参数闪切 | 瞬移、路径切割、命中反馈 | 长度不足时仍执行最短闪切，不消耗额外资源 |
| 鼠标右键 | 取消蓄力 | 时间恢复、预览淡出 | 无 |
| Esc | 暂停或继续 | 暂停菜单、战斗冻结 | 无 |
| 1 / 2 / 3 或鼠标点击 | 选择升级 | 卡片高亮，参数与形状更新 | 无 |

### 3.3 战斗状态

```text
出场 → 常态移动 ↔ 蓄力瞄准 → 闪烁切割 → 短暂冷却 → 常态移动
                  └→ 取消蓄力 → 常态移动
常态移动 / 蓄力瞄准 / 冷却 → 受伤 → 常态移动
任意战斗状态 → 生命归零 → 失败结算
任意战斗状态 → 升级 → 三选一暂停 → 返回原状态
9:00 → 首领战；首领死亡 → 胜利结算
```

### 3.4 基础数值【暂定，全部需手感测试】

| 参数 | 默认值 | 备注 |
|---|---:|---|
| 最大生命 | 100 | 接触与敌方攻击均可扣血 |
| 移动速度 | 250 像素/秒 | 以 1280×720 逻辑分辨率为基准 |
| 蓄力时移动速度 | 常态的 65% | 保留微调落点的能力 |
| 受伤无敌 | 0.65 秒 | 防止敌潮同帧重复扣血 |
| 最短蓄力 | 0.10 秒 | 低于该时长按最短闪切处理 |
| 满蓄力时间 | 0.90 秒 | 指现实时间，不受世界减速影响 |
| 世界时间倍率 | 100% → 20% | 蓄力开始时用 0.12 秒平滑下降 |
| 基础切割长度 | 260 像素 | 同时是最大闪烁距离 |
| 基础切割宽度 | 24 像素 | 以路径中心线向两侧展开 |
| 基础切割伤害 | 40 | 同一敌人每次闪切只受伤一次 |
| 切割冷却 | 0.35 秒 | 从闪烁结束后计算 |
| 闪烁视觉时长 | 0.08 秒 | 逻辑位移瞬时完成，残影随后衰减 |
| 闪烁期间无敌 | 0.08 秒 | 短暂相位穿越；蓄力期间不无敌【已确认】 |

## 4. 闪烁切割规则

### 4.1 路径与判定

1. 起点为释放时玩家位置，终点为瞄准方向上的切割长度终点，并限制在竞技场内。
2. 伤害区域为起点到终点的**胶囊形路径**，不是只判定终点。
3. 玩家逻辑位置瞬时移动到终点；敌人以路径与自身几何碰撞体的相交结果判定命中。
4. 同一敌人每次闪切最多受到一次基础伤害，防止持续重叠导致重复结算。
5. 路径预览显示中心线、实际宽度边界、落点标记；高威胁预警覆盖在预览上方。
6. 预览中的预计命中目标仅做轮廓高亮，不显示自动锁定或自动修正。
7. 闪烁期间可穿过敌人与弹体，但不能穿出竞技场或越过首领实体封锁墙；蓄力期间始终可受伤。【已确认】

### 4.2 蓄力与形状

- 暂定采用“固定基础形状 + 强化改变参数”，蓄力主要提高伤害与释放完成度，避免与宽度、长度强化重复。
- 伤害系数：从 70% 线性增长至 100%；长度和宽度直接采用当前构筑值。
- 快速点按可用于紧急位移，满蓄力用于追求更高伤害与连穿收益。
- 世界减速影响敌人、弹体、生成器和战斗计时；不影响菜单、蓄力输入、音频采样播放与界面动画。
- 闪切不消耗独立资源，也不设置能量或热量条；仅由蓄力时间、受伤风险和冷却限制连续使用。【已确认】

### 4.3 连穿奖励【暂定】

- 单次闪切命中至少 3 个敌人时触发“连穿”。
- 从第 3 个目标起，每多命中 1 个敌人，本次伤害增加 8%，最多增加 40%。
- 连穿只强化本次切割，不生成永久增益。
- 命中数提高碎裂规模、音阶和计数显示，不无限增加震屏与顿帧。
- 设计目的：让玩家主动聚怪并寻找一条高价值路线。

### 4.4 失败反馈

- 空切：保留细短残光与较轻释放声，不触发命中顿帧。
- 落点危险：落点若位于已知敌方预警内，落点标记变为警告形状；不替玩家禁止释放。
- 蓄力受伤：预览出现短暂断裂，音效被压低，明确说明“减速不等于安全”。

## 5. 局内三选一构筑

### 5.1 升级流程

1. 敌人掉落经验碎片，进入吸附范围后自动飞向玩家。
2. 经验达到阈值时冻结战斗，展示三张强化卡。
3. 每张卡显示名称、正向效果、负向效果、当前等级，以及切割形状预览。
4. 选择后立即生效；不设刷新和禁用功能，保持切片简洁。
5. 同类强化可自由叠加；标注“唯一”的协议不可重复。

### 5.2 强化池（18 项，数值均为暂定）

| 名称 | 效果 | 取舍或限制 |
|---|---|---|
| 扩容协议 | 宽度 +35% | 长度 −12% |
| 穿刺协议 | 长度 +40% | 宽度 −20% |
| 超频协议 | 满蓄力所需时间 −18% | 基础伤害 −8% |
| 重载协议 | 伤害 +30% | 满蓄力所需时间 +15% |
| 磁轨协议 | 长度 +22%，冷却 −8% | 移动速度 −6% |
| 窄锋协议 | 宽度 −15%，伤害 +22% | 更低覆盖容错 |
| 余波 | 路径末端产生 50% 宽度的二次切割 | 二次伤害为基础伤害的 30%，唯一 |
| 回切 | 满蓄力闪切后，0.25 秒反向残切 | 残切伤害为 25%，唯一 |
| 分叉协议 | 落点向两侧发出短切线 | 主路径宽度 −12%，唯一 |
| 断点爆破 | 被切杀敌人产生小范围爆裂 | 爆裂伤害为本次击杀伤害的 20% |
| 连锁电弧 | 连穿 ≥4 时跳跃至附近目标 | 每次闪切最多触发 2 次 |
| 处决线 | 对生命低于 20% 的非首领敌人伤害 +60% | 对生命高于 80% 的目标伤害 −8% |
| 动能回收 | 连穿 ≥3 时返还 20% 冷却 | 单次闪切最多触发一次 |
| 完美窗口 | 满蓄力后 0.35 秒内释放，伤害 +25% | 超时后伤害 −10% |
| 相位护层 | 连穿 ≥5 时获得 1 层护盾 | 最多 1 层，抵挡一次伤害后消失 |
| 经验磁轨 | 经验吸附范围 +45% | 切割宽度 −5% |
| 紧急协议 | 生命低于 30% 时蓄力速度 +30% | 生命高于 70% 时伤害 −5% |
| 稳态核心 | 最大生命 +20，并回复 20 | 切割冷却 +8% |

### 5.3 构筑方向示例

- **宽幅清群**：扩容协议 + 断点爆破 + 相位护层。追求密集敌群中的覆盖率与生存。
- **长线穿刺**：穿刺协议 + 磁轨协议 + 连锁电弧。追求贯穿阵型与精确瞄准。
- **高速连切**：超频协议 + 动能回收 + 完美窗口。追求释放节奏与连续位移。
- 以上为组合示例，不设互斥路线，不限制跨方向选择。

### 5.4 叠加与边界【暂定】

- 百分比加法在同类升级内部累计，再作用于基础值；不同系统按文档规定顺序计算。
- 宽度、长度、蓄力时间和冷却均设置硬下限，防止构筑导致不可操作或无限循环。
- 原型阶段优先通过升级出现权重与上限控制异常组合，不引入复杂装备稀有度。

## 6. 敌人与首领

### 6.1 普通与精英敌人【暂定】

| 敌人 | 几何轮廓 | 行为 | 预警与应对 |
|---|---|---|---|
| 追迹三角 | 红色实心三角 | 直接追逐玩家，形成基础敌潮 | 转向明显；用路径聚怪后一次穿透 |
| 壁垒方块 | 橙色正方形 | 低速、高生命，阻挡安全路线 | 体型大、受击分区清晰；用高伤害或绕切 |
| 射线菱形 | 紫色菱形 | 保持距离并发射直线弹体 | 发射前显示细线与收缩轮廓；切断阵型后接近 |
| 冲锋双锥 | 黄红双锥 | 短暂锁定方向后高速冲锋 | 地面方向线持续可见；蓄力时需判断是否提前取消 |
| 精英变体 | 双层描边与尺寸放大 | 提升生命并附加一种行为修正 | 使用形状与图标，不仅依赖颜色 |

### 6.2 首领：协议监视者

- 核心体验：几何弹幕走位 + 攻击轮次后的核心暴露输出窗口。【已确认】
- 外形：多层同心六边形，各层对应一种攻击模块。【暂定】
- 目标：验证玩家能否在持续预警中安排蓄力、位移和输出，而非只检验清群能力。
- 攻击模块：
  1. **扇形扫描**：扇区预警后扫过，要求闪切穿越或离开。
  2. **几何封锁**：依次生成线段障碍，压缩安全区域。
  3. **核心暴露**：完成一轮攻击后短暂暴露核心，承受额外伤害。
- 阶段：生命低于 50% 时缩短攻击间隔，但不引入未展示过的新规则。
- 首领不受普通处决效果影响，控制链与无限击退不适用。

## 7. 场景、镜头与界面

### 7.1 竞技场

- 单张固定尺寸的深色网格竞技场，边界由低亮霓虹线构成。【暂定】
- 镜头平滑跟随玩家，避免大幅缩放；高密度战斗时只进行轻微视野扩展。
- 原型不加入随机地图、地形寻路、机关谜题或剧情场景。

### 7.2 战斗界面

- 左上：生命、护盾、等级。
- 屏幕上方：局内计时与首领状态。
- 玩家附近：蓄力环、冷却环、落点警告。
- 准星附近：连穿数量；避免在屏幕中央堆叠伤害数字。
- 升级界面：三卡并列，显示正负效果和形状变化。
- 结算界面：胜负、击杀、最高连穿、构筑列表、局外资源、重开。

### 7.3 信息层级

1. 致命预警与首领攻击。
2. 玩家、敌人与弹体。
3. 切割预览与实际路径。
4. 经验、连穿和界面提示。
5. 残光、碎片、背景网格等装饰效果。

## 8. 美术与打击反馈

### 8.1 视觉规范【暂定】

| 用途 | 建议颜色 | 表现原则 |
|---|---|---|
| 背景 | #070A12 | 低对比网格，不与弹体争夺注意力 |
| 玩家与友方路径 | #63F3FF | 青色实心核心 + 空心轮廓 |
| 普通敌人 | #FF3D8D | 品红轮廓，按形状区分类别 |
| 高威胁与精英 | #FFC857 | 琥珀色配合双线或三角警示图形 |
| 经验与稀有奖励 | #B28CFF | 紫色小几何碎片 |
| 文字 | #EAF6FF | 高对比，避免过细霓虹字体 |

### 8.2 一次命中的反馈顺序

**释放瞬态声 → 起点残影 → 路径残光 → 命中停顿 → 几何断裂与定向飞散 → 金属泛音 → 连穿计数 → 经验掉落**

| 反馈 | 暂定参数 | 约束 |
|---|---|---|
| 普通命中停顿 | 35 毫秒 | 不冻结玩家输入缓存 |
| 连穿命中停顿 | 最高 55 毫秒 | 不随命中数无限增长 |
| 首领破防停顿 | 最高 80 毫秒 | 与阶段转换分开触发 |
| 普通震屏 | 1–2 像素，60–90 毫秒 | 可关闭 |
| 连穿震屏 | 最高 5 像素，120 毫秒 | 有全局上限 |
| 路径残光 | 120–180 毫秒衰减 | 不遮住后续预警 |
| 几何碎片 | 每个敌人 3–6 片，快速缩小 | 对象池复用，限制同屏数量 |
| 色差与全屏闪光 | 仅用于高价值事件 | 默认低强度，可关闭 |

### 8.3 可访问性

- 震屏强度：100% / 50% / 关闭。
- 全屏闪光与色差：独立开关。
- 高对比预警：增加形状、描边和透明度，不只替换颜色。
- 音量：主音量、音乐、音效分别调整。
- 蓄力减速与镜头设置不改变伤害判定，避免视觉设置影响规则。

## 9. 音频设计

### 9.1 风格

电子 glitch（数字故障）+ 金属切割瞬态 + 深色电子节拍。【已确认】

### 9.2 动作音效分层

| 事件 | 音频组成 | 变化规则 |
|---|---|---|
| 蓄力 | 上升音调、窄带噪声、轻微脉冲 | 音高随蓄力程度上升，取消时快速下落 |
| 释放 | 短噪声瞬态、低频推进、数字切片 | 长度影响低频体感，速度影响音高 |
| 命中 | 金属泛音、短促主体撞击 | 按敌人材质轮廓变化，不只提高音量 |
| 连穿 | 逐级上行音阶、更宽声场 | 命中数分层，不无限叠加播放 |
| 空切 | 轻释放声、无金属命中层 | 清楚区分命中与未命中 |
| 受伤 | 低频中断、短失真 | 避免与击杀声混淆 |
| 升级 | 三音符确认动机 | 选择后短促收束，不打断节奏 |

### 9.3 混音与性能约束【暂定】

- 同类命中声限制并发数量，多杀时合并为一次主音效加少量泛音。
- 首领预警、玩家受伤和释放声拥有更高优先级。
- 音乐不盖过 1–4 kHz 的关键动作信息。
- 浏览器 Demo 优先使用 Web Audio 合成与自制短采样；不引入来源不明音频。

### 10.1 资源与流程

- 失败保留本局已获取数据碎片的 70%；胜利全额保留并获得首领奖励。【已确认】

### 10.2 永久基础升级【暂定】

| 项目 | 每级效果 | 上限 | 设计约束 |
|---|---:|---:|---|

- 解锁条件采用可理解的挑战，例如完成一局、达到指定连穿、击败首领。
- 不包含随机付费抽取、体力、每日签到或强制在线。

## 11. 浏览器 Demo 技术规格

### 11.1 技术路线

- Canvas 2D 负责几何绘制、粒子与界面；Web Audio 负责实时音效与混音。【暂定】

### 11.2 Unity 迁移边界

- 切割参数、升级效果、敌人状态与反馈事件使用数据化定义，避免把数值散落在绘制代码中。
- 浏览器版只用于验证操作、规则与反馈；不承诺代码可直接迁移。
- Unity 正式版版本、渲染管线和目标平台在正式开工前单独确认。

### 11.3 素材与授权

- 原型使用程序生成几何图形、自制界面和合成音频。
- 当前不采购、不调用外部付费服务，不上传项目素材。
- 若后续引入字体、音乐、插件或商店资源，分别记录作者、许可、来源与使用范围。

## 14. 试玩测试与成功标准

### 14.1 新手测试脚本

1. 不阅读外部说明，从标题界面开始游戏。
2. 观察玩家是否能移动、蓄力、取消并完成一次闪切。
3. 首次升级时选择一项强化，并描述实际变化。
4. 在敌潮中尝试一次至少命中 3 个目标的闪切。
5. 经历一次受伤和一次失败，判断原因是否清楚。
6. 重开并完成一局，记录首领战与结算状态。

### 14.2 通过阈值【暂定】

- 至少 4/5 名首次试玩者在 30 秒内完成一次有效闪切。
- 至少 4/5 名首次试玩者在首次升级后能说出“覆盖、距离或节奏”中的一种实际变化。
- 至少 3/5 名首次试玩者在 2 分钟内主动完成一次 3 目标以上连穿。
- 试玩者能区分空切、命中和自身受伤；关键反馈识别率目标为 80%。
- 连续重开 10 局，无无法操作、胜负重复结算、升级卡无法选择或暂停后计时异常。
- 在目标测试设备上记录平均帧率、低帧与同屏数量；未实测前不宣称性能达标。

### 14.3 回归检查

- 蓄力时世界减速，但玩家仍按规则受伤。
- 同一敌人不会被同一路径重复伤害。
- 升级暂停、菜单暂停和首领出场不会推进战斗计时。
- 长度、宽度、冷却与蓄力时间达到下限时仍可操作。
- 震屏和闪光关闭后，预警与命中信息仍完整。
- 胜利、失败和重开不会重复写入局外资源。

## 15. 风险与替代方案

| 风险 | 观察信号 | 首选调整 |
|---|---|---|
| 手动蓄力与幸存者节奏冲突 | 玩家长时间按住蓄力、不愿移动 | 缩短满蓄力时间，提高短切收益 |
| 减速导致缺乏压力 | 玩家可无限等待安全窗口 | 保持受伤、加入冲锋预警，评估减速资源 |
| 构筑存在唯一最优属性 | 所有玩家只堆同一项 | 强化取舍、敌人组合与属性下限共同调整 |
| 特效遮挡预警 | 玩家无法说明受伤来源 | 降低装饰透明度，预警始终置顶 |
| 多杀音效失真或混浊 | 高频叠加、音量突然上升 | 合并命中声、限制并发、设置总线峰值 |
| 内容范围拖慢手感验证 | 大量时间用于局外和敌人数量 | 先完成 3 分钟战斗沙盒，再接完整单局 |
