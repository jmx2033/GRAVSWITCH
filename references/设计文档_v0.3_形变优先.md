# 《闪切协议》游戏设计文档 v0.3

> 形变优先校准版｜不是更多数值，而是更多切割形状

- 更新日期：2026-10-26
- 版本关系：本文替代 v0.2 的设计基线；v0.2 保留为已经实现并测试过的 3 分钟沙盒规则快照

## 1. 产品定位与设计主张

### 1.1 一句话体验承诺

> 在 3 分钟的几何围攻中，用一次有风险的蓄力换一条穿过敌群的切割路线，并亲眼看到自己的刃形被蓄力与三选一不断改写。

### 1.2 差异化主张

本作不以“更多敌人、更多数值、更多稀有度”竞争，而以三个可观察的差异点立身：

1. **蓄力改变形状，而不只改变伤害。** 按住左键时，刀刃会经历三段可见的形变；等待本身就在决定这一刀覆盖什么。
2. **强化改变轮廓，而不只提高数字。** 卡牌必须改变宽度、长度、折角、分裂、残影、连锁或尾迹中的至少一项。
3. **颜色有唯一语法。** 玩家品红、敌方冷青、切割白热、预警琥珀；玩家能在一秒内分清“谁是我、谁危险、哪里被切开”。

### 1.3 设计判断口径

每次提出新内容时，必须回答：

- 它是否改变玩家对路线或释放时机的判断？
- 玩家不看数值时，能否从预览、轮廓或声音说出变化？
- 它是否让敌方预警更难读、设备更卡，或稀释已有构筑？
- 它是否只是“再来一张伤害 +X% 的牌”？

任一问题答不上来，内容不进入当前版本。

### 1.4 形变的七个维度

| 维度 | 玩家感知 | 对应视觉 | 现有或候选来源 |
|---|---|---|---|
| 宽 | 一刀覆盖更厚的敌群 | 刃带宽度和边缘厚度 | 扩容协议、蓄力三段 |
| 长 | 一刀穿过更远阵型 | 中心线长度、落点距离 | 穿刺协议、蓄力三段 |
| 折 | 路线在末端转弯 | 折角、第二段中心线 | 折线协议 |
| 分 | 一条变多条 | 分叉轮廓 | 分叉协议 |
| 残 | 主刀结束后仍有第二刀 | 延迟出现的平行残痕 | 残影协议 |
| 链 | 命中向邻近目标跳跃 | 白热折线电弧 | 连锁协议 |
| 尾 | 落点追加横向切口 | 落点十字或 T 形 | 余波协议 |

**硬规则：** 新卡至少改变上述一项；只增加伤害、冷却或移速的卡不得进入常规候选池。超频协议作为节奏牌保留，因为它改变蓄力窗口和出刀频率，属于可感知的操作变化。

阶段 0 只实现宽、长、尾、分、残与节奏；折线、连锁属于阶段 1，不在首轮 5 人测试中出现。

## 2. 版本范围与不做清单

### 2.1 当前 3 分钟沙盒仍包含

| 项目 | 内容 |
|---|---|
| 单局时长 | 3 分钟，时间到即完成 |
| 竞技场 | 1 张固定深色网格竞技场 |
| 玩家 | 1 个品红空心几何体，移动、瞄准、三段蓄力、闪切 |
| 敌人 | 追迹三角、壁垒方块；无远程、无冲锋、无精英 |
| 强化 | 6 项正式卡池，另 3 张仅用于前两次的训练校准卡；折线、连锁延后 |
| 结束条件 | 3:00 完成；生命归零失败 |
| 表现 | 顿帧、微震、几何碎片、霓虹切痕、分层合成音效 |
| 技术 | 单 HTML、零依赖、离线运行、键鼠操作 |

### 2.2 本版明确不做

- 首领、多阶段战斗、几何弹幕。
- 射线菱形、冲锋双锥、精英词缀。
- 局外数据碎片、永久属性、协议终端和成长存档。
- 18 项强化、条件触发型强化、稀有度、装备与角色选择。
- 多地图、剧情、手柄、移动端、联网、排行榜、商业化。
- 为“看起来更大”而增加敌人种类或卡牌数量。

### 2.3 阶段 0 的硬门槛

**在 6 项首发的 3 分钟沙盒没有通过第 12 节门槛前，以下内容一律不开发、不排期、不进入 Demo 菜单：**

- 首领与任何多阶段战斗。
- 远程敌人、冲锋敌人、精英词缀。
- 局外成长、永久属性、协议终端。
- 18 项强化池与条件触发型卡牌。
- 第二张地图、难度选择、角色选择。

阶段 0 的目标不是“做一个缩小版完整游戏”，而是用最小构建回答蓄力、闪切和形变三个问题。

### 2.4 局外养成的处理

本次建议中的“局外养成克制”作为**未来设计约束**写入第 10 节，但不在当前 MVP 内实现。先证明一局内的蓄力、爽感和形变成立，再评审是否加入局外。若三分钟试玩未通过，局外不启动。

## 3. 核心循环

### 3.1 秒级循环

**移动聚怪 → 鼠标瞄准 → 按住左键进入慢动作 → 观察三段刃形与危险落点 → 选择在第二段或第三段释放 → 闪切并结算路径 → 四件套反馈 → 拾取经验 → 三选一改变刃形 → 再次聚怪**

### 3.2 核心决策

| 决策点 | 玩家权衡 | 立即可见的结果 |
|---|---|---|
| 现在切还是再等 0.3 秒 | 薄刃保命，还是厚刃多杀 | 预览刃带在阈值处跳变，玩家仍会受伤 |
| 朝哪条路线切 | 穿过更多目标，还是落到安全位置 | 预计命中高亮与落点危险三角 |
| 选择哪张强化 | 更长、更宽、分叉或残影 | 卡片形状图与实战预览立即更新 |
| 是否继续拾取经验 | 冒险吸附，还是先脱离包围 | 经验吸附范围与紫色碎片流向 |

### 3.3 3 分钟节奏

| 时间 | 压力与目的 |
|---|---|
| 0:00–0:20 | 少量三角；首次升级目标在 20–30 秒内出现 |
| 0:20–0:35 | 三角密度提高，尝试第一次三目标连穿 |
| 0:35–1:20 | 加入壁垒方块，比较长度与宽度构筑 |
| 1:20–2:10 | 方块比例提高，检验分叉与残影是否改变路线 |
| 2:10–2:45 | 高密度混合敌潮，提供连续多杀高光 |
| 2:45–3:00 | 最后一波集中敌群，结算前形成明确高潮 |
| 3:00 | 停止生成，进入“沙盒完成”结算 |

## 4. 玩家与蓄力规则

### 4.1 输入映射

| 输入 | 行为 | 成功反馈 | 失败或受限反馈 |
|---|---|---|---|
| WASD | 八方向移动，斜向归一化 | 玩家位移与轻拖尾 | 到达边界时出现细线阻尼 |
| 鼠标移动 | 手动瞄准，不自动锁敌 | 尖端、准星、预览跟随 | 无 |
| 按住左键 | 开始并维持蓄力 | 世界慢放、三段刃形、升频音 | 冷却中只显示冷却环，不进入蓄力 |
| 松开左键 | 按当前阶段闪切 | 瞬移、残光、命中反馈 | 无资源消耗，进入冷却 |
| 右键 | 取消蓄力 | 世界时间恢复，预览淡出 | 无 |
| Esc | 暂停或继续 | 冻结战斗与计时 | 无 |
| 1 / 2 / 3 或点击 | 选择强化 | 卡片高亮，刃形立即更新 | 选择前战斗保持冻结 |

交互补充：

- 鼠标右键在游戏画布上必须阻止浏览器上下文菜单；右键只取消蓄力，不切换瞄准模式。
- 首次点击或按键时解锁并恢复 Web Audio 上下文；未解锁前不播放战斗音效。
- 鼠标移出画布时保留最后一次有效瞄准点，不把玩家朝向重置为 0°。

### 4.2 基础数值

| 参数 | 默认值 | 说明 |
|---|---:|---|
| 最大生命 | 100 | 接触伤害 |
| 常态移动速度 | 250 像素/秒 | 1280×720 逻辑基准 |
| 蓄力操控系数 | 常态 65% | 与世界时间倍率相乘 |
| 世界时间倍率 | 100% → 20% | 0.12 秒平滑过渡 |
| 满蓄力时间 | 0.90 秒 | 真实时间，不受世界减速影响 |
| 最短蓄力 | 0.10 秒 | 低于此值按第一段最短闪切处理 |
| 基础切割长度 | 260 像素 | 第二段蓄力的基准值 |
| 基础切割宽度 | 24 像素 | 路径中心线两侧总宽度 |
| 三段基础伤害 | 70% / 85% / 100% | 按蓄力阶段结算 |
| 切割冷却 | 0.35 秒 | 从闪烁结束后计算 |
| 闪烁无敌 | 0.08 秒 | 可穿敌人，不可穿出竞技场 |
| 受伤无敌 | 0.65 秒 | 防止同帧重复扣血 |

### 4.3 蓄力时所有角色同步慢放

【本轮决策】蓄力后不是“敌人变慢、玩家正常”，而是整个世界一起慢下来：

- 敌人移动、生成、经验吸附、战斗计时使用世界时间倍率。
- 玩家移动同样乘入世界时间倍率，再乘 65% 蓄力操控系数。
- 满减速时玩家实际移速约为 `250 × 0.65 × 0.20 = 32.5 像素/秒`；追迹三角约为 `82 × 0.20 = 16.4 像素/秒`。玩家仍能缓慢调整落点，但不能快速逃离包围。
- 鼠标输入、蓄力进度、界面动画和音频采样按真实时间更新。
- 蓄力期间始终可受伤；右键取消后世界时间在约 0.12 秒内恢复正常。

这条规则的目的不是增加操作延迟，而是让“按住蓄力”成为真正的承诺：你主动把所有人拖入慢动作，也把自己拖入危险。

### 4.4 三段蓄力与刃形

蓄力不再只提高伤害。每个阶段在视觉上明显改变刃形，并在阈值处“跳档”，避免连续变化导致玩家看不出区别。

| 阶段 | 真实蓄力时间 | 长度倍率 | 宽度倍率 | 伤害 | 刃形表现 |
|---|---:|---:|---:|---:|---|
| I 快切 | 0.10–0.34 秒 | 80% | 80% | 70% | 细白线，短残光 |
| II 标准 | 0.35–0.64 秒 | 100% | 100% | 85% | 白热核心 + 品红外缘 |
| III 过载 | 0.65–0.90 秒 | 118% | 130% | 100% | 厚白热核心、双层品红外缘、轻微故障闪烁 |

规则：

- 蓄力低于 0.10 秒按阶段 I 处理，仍执行最短闪切，不消耗额外资源。
- 达到阶段 III 后继续按住不再增加伤害或形状，只保持满蓄力状态。
- 阶段阈值取“超过或等于”，例如 0.35 秒即进入阶段 II。
- 预览在阈值处一次性展开，不随每一帧微小变化抖动；阶段切换用 60 毫秒亮度脉冲确认。
- 玩家身边显示三个小刻度，当前阶段常亮；满蓄力时第三个刻度变为白热。
- 超频协议同时压缩满蓄力时间和三段阈值，保持三段比例。

### 4.5 蓄力风险双组实测

0.90 秒满蓄力、20% 世界减速和 65% 操控系数不一定天然成立。阶段 0 必须用两组参数各测试至少 5 名玩家，再锁定默认值。

| 组别 | 满蓄力时间 | 世界减速 | 其他 |
|---|---:|---:|---|
| A 现默认 | 0.90 秒 | 20% | 三段阈值按比例 |
| B 短蓄力 | 0.65 秒 | 35% | 三段阈值按比例 |

A/B 仅作为开发构建参数，不进入玩家设置界面；两组使用相同敌人密度、相同卡池和相同初始属性。

观察记录：

- 每次蓄力实际按住时长，以及满蓄力后继续按住的时长。
- 满蓄力释放占比、蓄力中受伤次数、蓄力中取消次数。
- 玩家是否长时间按住等待绝对安全，以及是否觉得节奏拖慢。
- 玩家能否区分两组的手感；若不能，优先选择更短、更有压力的一组。

调整规则：

- 若超过半数蓄力在满蓄力后仍继续按住 0.4 秒以上，缩短满蓄力时间或提高蓄力期压力。
- 若满蓄力释放占比低于 25%，且玩家普遍只点按，检查收益是否不足，而不是先加资源条。
- A/B 结果必须记录设备和试玩版本；未测试前不把 0.90 秒/20% 当作定稿。

### 4.6 场地、碰撞与吸附尺寸

| 对象 | 逻辑尺寸 | 判定方式 |
|---|---|---|
| 竞技场 | 2400 × 1600 像素 | 矩形边界，中心点按玩家半径夹紧 |
| 镜头逻辑视野 | 1280 × 720 | 平滑跟随玩家，镜头不越出竞技场 |
| 玩家 | 碰撞半径 12，视觉半径 14 | 圆形碰撞体，空心三角绘制 |
| 追迹三角 | 碰撞半径 14，视觉半径 16 | 接触用圆形；路径命中用半径 14 |
| 壁垒方块 | 碰撞半宽 22，视觉半宽 26 | 接触用轴对齐方块；路径命中按半径 24 外接圆 |
| 经验碎片 | 视觉半径 3，拾取半径 8 | 进入玩家拾取半径后结算 |
| 基础吸附半径 | 180 像素 | 经验开始飞向玩家 |
| 玩家拾取半径 | 玩家碰撞半径 + 8 | 约 20 像素 |

补充规则：

- 玩家中心和敌人中心距离小于“玩家碰撞半径 + 敌人碰撞半径”时触发接触。
- 壁垒方块的接触使用方块半宽；路径命中允许使用外接圆，避免贴角时视觉命中但判定不中。
- 玩家位置始终夹紧在 `[碰撞半径, 场地尺寸 − 碰撞半径]` 内。
- 镜头在场地边缘停止，不显示场地外空白；UI 不随镜头缩放。
- 所有尺寸为逻辑像素，绘制时按画布缩放，不用屏幕像素参与判定。

### 4.7 经验与升级曲线

| 项目 | 默认值 |
|---|---:|
| 追迹三角经验掉落 | 2 枚 × 1 点 |
| 壁垒方块经验掉落 | 5 枚 × 1 点 |
| 吸附半径 | 180 像素 |
| 升级所需经验 | 10 / 18 / 28 / 42 / 58 / 78 |
| 累计经验 | 10 / 28 / 56 / 98 / 156 / 234 |

- 首次升级目标 20–30 秒；3 分钟内 5–6 次。
- 若首轮实测 30 秒内未升级，优先提高前 20 秒三角掉落或降低首级需求，不增加新敌人。
- 经验碎片在 24 秒后消失；消失不是失败惩罚，只是控制对象数量。
- 三选一冻结战斗、计时和音频事件队列，不冻结界面动画。

### 4.8 判定顺序与伤害归属

一次闪切在固定更新步内按以下顺序结算：

1. 释放事件在固定更新步开始时处理，先于本步敌人移动与接触检测；捕获释放瞬间的玩家位置、瞄准方向、当前蓄力阶段和卡牌参数。
2. 计算起点、终点和胶囊路径，生成本次闪切唯一的命中标记集合。
3. 对主路径内每个敌人标记一次、结算一次主伤害；标记不得跨闪切复用。
4. 主伤害结算后，玩家逻辑位置瞬移到终点，终点夹紧在竞技场内。
5. 立即开始 0.08 秒闪烁无敌，使用真实时间，覆盖之后的 5 个 60Hz 固定步（约 83 毫秒）。
6. 按“余波 → 分叉 → 延迟残影”的固定顺序结算追加效果；每个追加效果使用自己的命中集合。
7. 闪烁无敌消失后，下一次固定步才重新检测玩家接触伤害。
8. 本帧不重复检查同一敌人对玩家的接触伤害；玩家 0.65 秒受伤无敌独立生效。

边界定义：

- 阶段 0 没有敌方弹体；未来加入弹体时，释放事件先结算路径伤害与瞬移，再由 0.08 秒无敌覆盖随后的弹体碰撞。
- 如果闪切落点与敌人重叠，0.08 秒内不受伤；无敌结束后仍重叠才按接触伤害结算。
- 同一敌人被主路径命中一次后，本次闪切的主路径不再结算第二次；余波、分叉、残影等各自最多再结算一次。
- 命中标记在闪切结算完成时立即清除，不做跨帧缓存。
- 3:00 完成与生命归零在同一步发生时，完成优先；结算只触发一次。
- 暂停、三选一和失焦时停止所有世界更新，不推进计时、敌人、经验和动画事件队列。

### 4.9 计算顺序与下限

最终参数按以下顺序计算：

1. 读取基础长度、宽度、伤害和冷却。
2. 叠加同一类卡牌的百分比修正。
3. 乘以当前蓄力阶段倍率。
4. 应用连穿本次伤害加成。
5. 应用敌人类型或状态修正。
6. 执行硬下限。

| 参数 | 硬下限 |
|---|---:|
| 切割长度 | 90 像素 |
| 切割宽度 | 8 像素 |
| 满蓄力时间 | 0.28 秒 |
| 切割冷却 | 0.14 秒 |

## 5. 闪切判定与形变卡池

### 5.1 闪切判定

1. 起点为释放时玩家位置，终点为当前瞄准方向与当前阶段长度的交点，并限制在竞技场内。
2. 伤害区域为起点到终点的胶囊形路径，不是落点范围攻击。
3. 玩家逻辑位置瞬时到达终点，视觉残影随后衰减。
4. 同一敌人每次主路径只结算一次主伤害；追加效果按各自规则单独结算。
5. 闪烁 0.08 秒内可穿过敌人，不能越过竞技场边界。
6. 预览显示中心线、实际宽度边界、落点、预计命中目标与当前阶段。
7. 预览不自动修正方向，不锁敌，不替玩家禁止释放危险落点。
8. 命中 3 个及以上敌人触发连穿；阶段 0 先只用“音阶 + 计数 + 碎裂规模”表达爽感，伤害从第 3 个目标起每个额外目标只增加 4%，最多增加 20%。

### 5.2 阶段 0 六项强化卡池

【本轮决策】阶段 0 只保留 6 项。删除重载、磁轨、窄锋等偏数值牌；折线与连锁留到阶段 1。首发池为 5 项形变或行为牌 + 1 项节奏牌。

| 名称 | 形变维度 | 正向效果 | 取舍 | 叠加上限 |
|---|---|---|---|---|
| 扩容协议 | 宽 | 切割宽度 +35% | 长度 −12% | 3 |
| 穿刺协议 | 长 | 切割长度 +40% | 宽度 −20% | 3 |
| 超频协议 | 节奏 | 满蓄力时间 −18%，三段阈值同步压缩 | 基础伤害 −8% | 2 |
| 余波协议 | 尾 | 落点追加一次横向短切，长度 150、宽度 50%、伤害 30% | 唯一，不提高主路径 | 1 |
| 分叉协议 | 分 | 落点向两侧发出两条短切，长度 120、宽度 55%、伤害各 30% | 主路径宽度 −12% | 1 |
| 残影协议 | 残 | 主刀后 0.18 秒生成平行残影，偏移 20 像素、宽度 60%、伤害 35% | 主路径宽度 −8% | 1 |

补充规则：

- 残影沿主路径右侧平行偏移，不造成额外击退。
- 余波、分叉、残影持有后不重复进入候选池。
- 所有百分比在同类内部按加法累计，再乘蓄力阶段倍率。
- 阶段 0 不加入折线、连锁、条件触发型或稀有度。

### 5.3 前两次升级的新手保护

【本轮决策】首次升级约在 20–30 秒出现，前两次升级不能让新玩家先感到“变弱”。

- 第 1、2 次升级固定使用 3 张“校准卡”：扩容·校准、穿刺·校准、双刃·校准。
- 扩容·校准：宽度 +25%，无惩罚；穿刺·校准：长度 +25%，无惩罚；双刃·校准：宽度 +10%、长度 +10%，无惩罚。
- 三张校准卡都直接改变刃形，且总收益为正；不包含纯伤害或条件触发效果。
- 校准卡在卡面明确标记“训练增益：本次无取舍”，不隐藏规则。
- 同一张校准卡可以在第 2 次训练中再次出现，但第 2 次结束后永久退出候选池。
- 第 3 次升级起恢复 5.2 的完整卡池与完整取舍。
- 第 1、2 次升级仍然展示选择前后的刃形对比，避免玩家只看数字。
- 校准卡不计入正式卡牌的叠加上限，但其效果永久保留。

### 5.4 三选一候选与权重

- 每次提供 3 张不同卡片，支持鼠标点击和 1 / 2 / 3。
- 第 1、2 次升级固定展示 3 张校准卡。
- 第 3、4 次升级至少保证 2 张“形变牌”（宽、长、尾、分、残）。
- 尚未持有的唯一牌权重 1.3；可叠加形变牌权重 1.2；超频协议权重 1.0。
- 同一张三选一界面不重复出现同一张牌；达到叠加上限的牌不再出现。
- 唯一牌全部持有后，候选池保留扩容、穿刺、超频三张可叠加牌。
- 每张卡必须显示当前刃形与选择后刃形的对比图，而不是只列百分比。
- 卡面文案必须回答“操作上发生了什么”，例如“刃带更厚，落点更近”，不能只写“伤害 +30%”。

### 5.5 阶段 1 才允许加入的两张牌

只有阶段 0 全部通过第 12 节门槛后，才允许实现下列牌；它们不进入首轮 5 人测试。

| 名称 | 形变维度 | 效果 | 取舍 | 加入条件 |
|---|---|---|---|---|
| 折线协议 | 折 | 落点向瞄准方向左侧折出 30° 第二段 | 主路径伤害 −5%，唯一 | 阶段 1 |
| 连锁协议 | 链 | 主刀命中 ≥4 时电弧跳向 2 个附近目标 | 主路径伤害 −8%，唯一 | 阶段 1 |

阶段 1 的完整卡池上限为 8 项，仍不是 18 项。18 项强化必须另行评审，不属于当前阶段 0 或阶段 1 的默认交付。

### 5.6 升级后的即时反馈

1. 选择卡牌后，战斗立即解除冻结。
2. 当前蓄力预览下一次出现时必须使用新形状，不等待再次升级。
3. 屏幕中央显示一句不超过 14 个字的变化提示。
4. 玩家身边的三段刻度保持当前蓄力状态，不因升级重置。
5. 卡片加入构筑列表，结算页按获得顺序展示。

## 6. 敌人与压力来源

### 6.1 两类敌人

| 敌人 | 轮廓与颜色 | 基础生命 | 速度 | 接触伤害 | 行为与应对 |
|---|---|---:|---:|---:|---|
| 追迹三角 | 冷青实心三角 | 40 | 82 像素/秒 | 12 | 持续追逐，形成可聚拢敌潮；聚怪后用宽刃或长刃穿透 |
| 壁垒方块 | 冷青偏钢蓝双层方框 | 180 | 43 像素/秒 | 20 | 低速、高生命，压缩安全空间；用长度绕过或厚刃硬切 |

### 6.2 生成规则

- 0:00–0:35 只生成追迹三角。
- 0:35 后按比例加入壁垒方块。
- 随时间缩短间隔、提高同屏上限，不增加新种类。
- 所有敌人在镜头外围生成，避免突然出现在玩家身上。
- 本版不设置精英、金色描边或额外词缀。

### 6.3 可读性约束

- 敌人与玩家首先靠形状区分，其次靠颜色；即使关闭颜色，空心玩家仍能与实心敌人区分。
- 高威胁接触预警使用琥珀色虚线圈和实体描边，不允许被切割残光盖住。
- 敌方不得使用品红，玩家不得使用冷青，切割特效不得被误认为敌方弹体。
- 壁垒方块受击时显示生命条，但生命条不属于攻击预警，不得遮挡玩家落点。

## 7. 打击反馈：手感四件套

### 7.1 四件套定义

| 反馈 | 默认参数 | 设计目的 | 约束 |
|---|---|---|---|
| 命中顿帧 | 普通 35ms，连穿最高 55ms | 让刀刃确实“切进去了” | 不冻结输入缓存和界面动画 |
| 屏幕微震 | 普通 1–2px / 60–90ms，连穿最高 5px / 120ms | 给命中重量 | 全局上限，可关闭或降至 50% |
| 几何碎片爆散 | 每个敌人 3–6 片，沿切割方向飞散 | 让敌人“断裂”而非消失 | 对象池复用，总活跃碎片上限 240 |
| 霓虹切痕残留 | 120–180ms 衰减，白热核心 + 品红外缘 | 留下可读的切割路径 | 始终低于预警层级，不用全屏滤镜 |

### 7.2 一次命中的固定顺序

**释放瞬态声 → 起点残影 → 路径白热残光 → 短顿帧 → 几何碎裂 → 金属泛音 → 连穿计数 → 经验吸附**

空切保留短残光和轻释放声，不播放金属命中层，不触发顿帧。

### 7.3 打击层级

1. 敌方预警与危险落点。
2. 玩家、敌人和即将命中的目标轮廓。
3. 切割预览与白热残痕。
4. 命中碎片、连穿数字和经验。
5. 背景网格、扫描线和环境装饰。

后层不得使用比前层更高的亮度、对比度或持续时间。预警出现时，装饰残光自动降至 50% 透明度。

### 7.4 音效分层

音效必须按以下顺序形成一条可辨认的动作链：

1. **蓄力低频**：55–140Hz 的缓慢上升共振，叠加低通噪声；阶段 III 增加轻微高频泛音，但不盖过敌人接近声。
2. **闪烁高频**：2–6kHz 的短瞬态，持续 30–50ms，表示相位穿越。
3. **切割爆音**：45–90Hz 低频冲击 + 2–5kHz 金属噪声，切割越长低频体感越明显。
4. **连穿音阶**：从第 3 个目标起逐级上行，每个额外目标升高一个音级，最多播放 5 层；多杀合并为一次主音效加少量泛音。

约束：

- 空切只保留闪烁高频和轻释放声，不播放金属层。
- 受伤使用低频中断和短失真，不与击杀音混淆。
- 同类音效限制并发，避免高密度敌潮中削波。
- 所有音效使用 Web Audio 合成或自制采样，不加载来源不明素材。
- 必须在第一次有效点击、按键或开始按钮手势中创建或恢复音频上下文；上下文处于挂起状态时不排队播放战斗音效。
- 主总线设置限幅器，峰值上限约 −1 dBFS；总并发音源上限 16，同类命中声上限 8，超出时合并为一次主音效。
- 暂停或三选一时停止蓄力振荡器并将音乐压低，恢复后不补播暂停期间的音效。
- 重开时必须停止上一局蓄力声、清空音效并发计数，并重置音乐节拍，禁止跨局残留。

### 7.5 低端设备保护

- 普通画质：碎片上限 240、残痕上限 80、画布像素比上限 2。
- 低画质：碎片上限 120、残痕上限 40、画布像素比上限 1。
- 禁止在每次战斗帧对整张战场重复绘制或使用全画布滤镜；色差只能作用于局部切割残痕。
- 敌人、经验、碎片和残痕使用对象池；离屏对象不参与绘制。
- 设置中的震屏、闪光、色差、高对比预警只改变表现，不改变命中、伤害和减速规则。

## 8. 色彩与视觉语法

### 8.1 色彩角色

【本轮决策】色彩不再采用“纯黑底 + 通用霓虹线”，而是固定职责：

| 角色 | 颜色 | 使用范围 |
|---|---|---|
| 深空底 | `#070A12` | 全屏背景，不做纯黑 |
| 环境层 | `#0B1220` / `#132C3C` | 网格、边界、低对比装饰 |
| 敌方冷青 | `#56D9E8` | 敌人轮廓与接触预警底层 |
| 壁垒钢青 | `#7FA9B3` | 方块内层线框，仍属冷青族 |
| 玩家品红 | `#FF3D8D` | 玩家轮廓、蓄力环、友方身份 |
| 切割白热 | `#F4FFFF` | 刀路核心、命中瞬间、连穿刻度 |
| 预警琥珀 | `#FFC857` | 危险落点、接触警告，禁止装饰使用 |
| 经验紫 | `#B28CFF` | 经验碎片，仅占画面很小面积 |
| 界面文字 | `#EAF6FF` | HUD、标题、结算 |

### 8.2 面积与层级

- 背景与环境约占画面 70%。
- 敌方冷青约占 20%，且不铺满背景。
- 玩家品红、切割白热约占 10%，作为视觉焦点。
- 预警琥珀与经验紫只做局部强调，不得大面积铺色。
- 同一画面最多出现一条白热主刀；追加效果降低亮度，不争夺主路径。

### 8.3 三条不可破坏的规则

1. **品红只属于玩家。** 敌人、弹体、经验、UI 强调均不得使用品红，否则玩家会误判归属。
2. **白热只属于切割。** 普通 UI、经验、背景装饰不使用近白色高亮，保证“画面发白 = 有刀切过”。
3. **琥珀只属于危险。** 预警、落点警告和受伤反馈使用琥珀；装饰和升级卡片不使用，避免“危险色疲劳”。

### 8.4 极简但不空洞

- 背景使用两层低对比网格与缓慢扫描，不使用大面积纯黑。
- 敌人死亡时留下短时间的方向性断裂线，强化“被切开”的形状记忆。
- 切割残光采用白热核心、品红外缘和极轻的故障闪烁；故障闪烁不改变路径判定。
- 所有装饰透明度低于主体，预警始终绘制在最上层。

### 8.5 可访问性

- 高对比预警增加描边、虚线和三角形图标，不只替换颜色。
- 玩家为空心三角，敌人为实心图形；关闭颜色后仍能区分阵营。
- 提供“切割预览高对比模式”：预览外侧加暗色描边、中心线改为实线、宽度边界加白色虚线，避免与背景网格混在一起。
- 高对比模式只改变预览外观，不改变实际路径、宽度或伤害。
- 震屏、闪光、色差、高对比预警和高对比切割预览独立开关。
- 主音量、音乐、音效分别可调。
- 视觉设置不得改变切割判定或世界减速。

## 9. 界面信息架构

### 9.1 HUD

- 左上：生命、等级、经验条、当前构筑摘要。
- 上方：3:00 倒计时和世界时间倍率提示。
- 右上：击杀、最高连穿、本次连穿。
- 玩家附近：三段蓄力刻度、冷却环、危险落点标记。
- 准星附近：预计命中数与“可连穿”提示。
- 不显示局外货币、永久属性或未实现内容入口。

### 9.2 三选一

- 三张并列卡片，写明名称、形变维度、正向效果、取舍和当前等级。
- 卡片右上明确标记“唯一”“可叠加”或“训练校准”，且显示当前叠加上限。
- 卡片上半部分显示当前刃形与候选刃形的前后对比。
- 支持鼠标点击和数字键 1 / 2 / 3。
- 选择后立即返回战斗，不播放拖慢节奏的奖励动画。
- 卡片不使用琥珀危险色作为主色，避免与预警语义冲突。

### 9.3 结算

展示完成或失败状态、存活时间、击杀数、最高连穿、闪切次数、有效命中率和本局强化列表。不展示局外资源、永久成长或下一局战力提示。

## 10. 局外养成：克制型侧向解锁

> 本节是未来方向，不属于当前 3 分钟 MVP。只有三项核心验证通过后，才允许进入局外评审。

### 10.1 设计目的

局外只提供“换一种开始方式”和“换一种听感/视觉表达”，不提供永久攻击力、生命值或移速堆叠，避免稀释局内三选一的取舍。

### 10.2 允许的解锁类型

| 类型 | 示例 | 规则 |
|---|---|---|
| 切割模组 | 宽幅起始、长刃起始、脉冲起始 | 只改变起始形态，正负效果成对出现 |
| 起始形态 | 标准刃、折线刃、残影刃 | 改变第一刀的几何形状，不直接加伤害 |
| 音效皮肤 | 金属、磁带、玻璃、故障 | 只改变听感，不改变判定 |
| 切痕皮肤 | 白热、冷光、碎裂边 | 保持白热主路径语义，不改变阵营颜色 |

### 10.3 明确禁止

- 永久攻击力、最大生命、切割伤害、冷却缩减等纯数值成长节点。
- 五级属性树、装备稀有度、随机词条和抽卡。
- 每日签到、体力、限时商店和强制在线。
- 用局外资源直接购买高连穿或高伤害。
- 失败后永久加成的“补偿型”成长。

### 10.4 解锁节奏

- 主要通过完成一局、达到指定连穿或体验不同起始形态解锁。
- 解锁是侧向选择，不是严格更强；每项模组都必须有一个明确代价。
- 不以延长游戏时间作为唯一解锁条件。
- 局外界面只展示已解锁模组、音效皮肤和试玩记录。

## 11. 风险登记与硬阈值

| 风险 | 可观察信号 | 处理动作 | 硬阈值 |
|---|---|---|---|
| 与幸存者类或“几何回战”同质化 | 试玩者只描述为“换皮幸存者”，说不出本作独特动作 | 保持形变牌优先、三段蓄力、白热切割三条差异；停止增加普通数值牌 | 5 名试玩者中至少 4 人能说出一种独特操作或形状 |
| 光效过载导致判定看不清 | 玩家说不清受伤来源、找不到落点或把残影当敌人 | 降低装饰透明度，限制白热与琥珀面积，预警置顶；提供 50% 与关闭震屏 | 5 名试玩者中至少 4 人能指出受伤来源 |
| 低端设备掉帧 | 连切、高密度敌潮时帧间隔超过 20ms | 启用低画质、减少碎片与残痕、禁止全画布滤镜、复用对象池 | 目标设备 1280×720 下 p95 帧间隔 ≤16.7ms；未实测前不宣称达标 |
| 名称与“几何回战”过于接近 | 玩家混淆、商店搜索结果相邻、传播时被简称为同一作品 | 正式命名前完成商标和商店同名检索；宣传不使用近似副标题；必要时改名 | 上架前必须完成命名检索，不使用未清权的暂定名 |
| 蓄力三段导致等待过久 | 玩家长时间按住不释放，敌潮压力消失 | 缩短阈值、提高低段收益、增加包围密度；不改资源系统 | 若多数玩家只在第三段释放且觉得节奏拖慢，评估阈值 |
| 形变牌导致操作复杂 | 玩家无法解释分叉、残影或后续折线效果 | 预览显示完整轮廓；卡面用一句动作描述；必要时减少同时存在的特殊效果 | 首次升级后 4/5 玩家能说出形状变化 |

### 11.1 同质化的具体对策

- 不把“更多敌人/更多卡牌”作为宣传重点。
- 宣传语必须围绕“蓄力换形、路线切割、白热刀痕”，而不是“幸存者 + 几何皮肤”。
- 每张卡都必须改变轮廓或路径行为，避免构筑退化为攻击力数字比较。
- 试玩访谈中记录玩家自发使用的描述；若多数人只用“像某某游戏”描述，停止扩内容，先改核心体验。

### 11.2 视觉噪声预算

- 同一时间最多 1 条主白热刀路、1 个琥珀危险提示、1 个白热落点标记。
- 碎片和残痕总亮度不得高于主刀；预警出现时装饰自动降亮。
- 任何全屏闪光不超过 16% 不透明度，默认低强度，可关闭。
- 色差只在连穿或高价值命中触发，持续不超过 0.13 秒。

## 12. 阶段门槛：先沙盒，后切片

### 12.1 硬性阶段规则

**3 分钟沙盒没有验证手感前，不做首领、局外养成和 18 项强化。**

这不是建议，而是开发准入条件：

- 阶段 0 的构建不得出现首领代码、局外存档、18 项强化配置表或未实现入口占位。
- 未通过全部门槛，不允许用“先做一点以后再说”的方式提前开发后续内容。
- 任何后续阶段的范围变更，都必须先记录阶段 0 的实测证据，再重新评审。
- 阶段 0 通过前，所有内容讨论以三个验证目标为准，不以世界观、内容量或商业化目标扩张。

### 12.2 阶段 0：3 分钟手感沙盒

| 项目 | 阶段 0 范围 |
|---|---|
| 竞技场 | 1 张，2400×1600 逻辑尺寸 |
| 玩家 | 1 名，移动、瞄准、三段蓄力、闪切 |
| 敌人 | 追迹三角、壁垒方块，共 2 类 |
| 强化 | 6 项首发；前两次为无负向校准卡 |
| 时长 | 3 分钟；时间到完成，生命归零失败 |
| 系统 | 暂停、结束、重开、音画设置 |
| 明确不做 | 首领、远程、冲锋、精英、局外、18 项强化、第二地图 |

阶段 0 要回答的问题：

1. 玩家是否愿意主动蓄力，而不是只点按。
2. 穿越敌群的多目标闪切是否有明确、可重复的爽感。
3. 不看数值时，玩家是否能感到宽度、长度、节奏或残影发生了变化。

### 12.3 阶段 0 出口条件

只有下列条件**全部满足**，才允许进入阶段 1：

| 门槛 | 通过条件 | 证据形式 |
|---|---|---|
| 有效闪切 | 至少 4/5 人在 30 秒内完成一次有效闪切 | 5 人新手试玩录像或操作记录 |
| 主动蓄力 | 至少 3/5 人愿意在后续闪切中继续蓄力 | 访谈 + 蓄力时长统计 |
| 三目标连穿 | 至少 3/5 人在 3 分钟内主动完成一次 3 目标以上连穿 | 战斗日志 |
| 形状可感知 | 至少 4/5 人能说出宽度、长度、节奏或残影中的一种变化 | 升级后访谈 |
| 反馈可区分 | 至少 4/5 人能区分空切、命中与自身受伤 | 现场指认 |
| 颜色可读 | 至少 4/5 人能在 1 秒内指出玩家、敌人与危险落点 | 静帧识别测试 |
| 流程稳定 | 连续重开 10 局无卡死、重复结算、暂停计时异常 | 回归记录 |
| 音频稳定 | 首次手势后正常解锁；高密度命中无削波或残留 | 浏览器实测 |
| 性能基线 | 目标设备记录 p95 帧间隔、低帧和同屏数量 | 性能记录；未测前不宣称达标 |
| 蓄力参数 | A/B 两组各完成至少 5 人对比并记录 | 参数对比表 |

任一条件未满足，阶段 1 不启动，先修阶段 0。不允许用“后续内容会解决手感问题”作为放行理由。

### 12.4 阶段 1：垂直切片

阶段 1 只有在 12.3 全部通过后才启动。它是独立的新范围，不复用阶段 0 的通过结论自动放行所有内容。

阶段 1 的初始上限：

- 4 类敌人：增加射线菱形和冲锋双锥。
- 卡池扩展到 8 项：阶段 0 六项 + 折线 + 连锁。
- 仍不做局外、18 项强化和商业化。
- 若加入首领，安排在 8:30 出现，使实际战斗窗口约 90 秒；首领生命按“3–4 个核心输出窗口”反推，不先拍血量。
- 精英、首领、条件触发牌必须分别经过范围评审，不能因“已经做了 4 类敌人”而顺带加入。

### 12.5 阶段 2 之后

- 18 项强化与完整首领池属于阶段 2，只有阶段 1 达到自身验收后才允许。
- 局外养成属于阶段 3，只有 3 分钟沙盒和阶段 1 均已通过后才允许；即使加入，也必须遵守第 10 节的侧向解锁约束。
- 条件触发型强化（完美窗口、紧急协议、相位护层）延后；若未来加入“完美窗口”，蓄力环满时必须变白并出现短促脉冲，超时变灰，不能只靠隐藏计时。
- 本文不把阶段 2、阶段 3 视为已批准范围，也不为其预留代码或菜单入口。

## 13. 验证与停止条件

### 13.1 三个核心假设

| 假设 | 通过证据 | 不通过信号 |
|---|---|---|
| 蓄力有吸引力 | 多数闪切前主动蓄力，能说出等待的理由；能区分三段刃形 | 全程点按，认为蓄力只是拖慢自己 |
| 闪切有爽感 | 主动追求多目标路线，能区分空切、命中和受伤 | 只当代步，命中反馈无记忆点 |
| 形状变化可感知 | 不看数值能说出“变宽、变长、变折、会分叉”等 | 只觉得伤害变大，操作感没变 |

### 13.2 新手试玩脚本

1. 不阅读外部说明，从标题开始。
2. 20 秒内完成一次移动、蓄力和闪切。
3. 尝试一次快速切和一次满蓄力切，说出刃形差异。
4. 第一次升级时选择一张卡，说出轮廓发生了什么变化。
5. 尝试一次至少命中 3 个目标的闪切。
6. 在受伤后指出伤害来源。
7. 完成或失败后立即重开一次，观察结算是否正常。

### 13.3 通过阈值

- 至少 4/5 名首次试玩者在 30 秒内完成有效闪切。
- 至少 4/5 名首次试玩者能说出长度、宽度、分叉、残影或节奏中的一种变化。
- 至少 3/5 名首次试玩者在 3 分钟内主动完成一次 3 目标以上连穿。
- 至少 3/5 名试玩者表示愿意继续主动蓄力。
- 至少 4/5 名试玩者能区分空切、命中和自身受伤。
- 至少 4/5 名试玩者能在 1 秒内指出玩家、敌人和危险落点。
- 前两次升级不出现负向效果，第三次起才出现完整取舍。
- 同一敌人不会被同一主路径重复伤害；落点与敌人重叠时 0.08 秒无敌按 4.8 的判定顺序生效。
- 高对比切割预览开启后，预览路径、宽度边界与危险落点仍与实际判定一致。
- 右键取消蓄力时不弹出浏览器菜单，取消后 0.12 秒内世界时间恢复。
- 首次手势后音频正常解锁；高密度命中不超过并发上限且无削波。
- 连续重开 10 局无卡死、重复结算、升级无法选择或暂停后计时异常。
- 重开后敌人、经验、碎片、残痕数组为空，上一局蓄力振荡器已停止，音频并发计数归零。

### 13.4 停止条件

出现以下任一情况，不进入远程、冲锋、精英、首领和局外开发：

- 玩家普遍只点按，不愿蓄力。
- 玩家无法感知三段刃形或形变卡的变化。
- 玩家说不清受伤来源，或光效遮挡预警。
- 3 分钟流程无法稳定开始、暂停、结束和重开。
- 目标设备上连切帧间隔持续超过 20ms，且低画质仍无法恢复。
