## 1. 这一版只回答三个问题

### 1.1 验证目标

1. **蓄力是否愿意按**：玩家是否主动按住蓄力，而不是只点按闪切。
2. **闪切是否爽**：穿越敌群、切割多个目标时，是否有足够明确且可重复的爽感。
3. **三选一是否让形状肉眼变化**：升级后，玩家是否能不看数值也感到切割范围、长度或节奏已经改变。

### 1.2 一句话体验承诺

> 在 3 分钟的几何围攻中，用一次蓄力换一条穿过敌群的切割路线，并亲眼看到自己的切割形状被三选一逐步改写。

### 1.3 设计假设与判定方式

| 假设 | 可观察证据 | 不通过的信号 |
|---|---|---|
| 蓄力有吸引力 | 玩家多数闪切前会主动蓄力；能说出为何等待 | 全程点按、认为蓄力只是拖慢自己 |
| 闪切有爽感 | 玩家主动追求多目标路线，并愿意重开 | 只把闪切当代步，命中反馈无明显记忆点 |
| 形状变化可感知 | 玩家能不借助数值说出“变长、变宽、变快” | 升级后只觉得伤害变大，操作感没变 |

### 1.4 本版设计原则

- 先做好一次切割，再增加敌人和构筑数量。
- 所有 8 项强化都必须改变操作手感，不能只做隐藏数值。
- 反馈可以强，但敌方预警必须始终可读。
- 任何内容若不能服务三个验证目标，本版不做。

## 2. MVP 范围

### 2.1 本版包含

| 项目 | 内容 |
|---|---|
| 单局时长 | 3 分钟，时间到即完成沙盒 |
| 竞技场 | 1 张固定深色网格竞技场 |
| 玩家 | 1 个几何角色，移动、瞄准、蓄力、闪切 |
| 敌人 | 追迹三角、壁垒方块两种；无远程、无冲锋、无精英 |
| 强化 | 固定 8 项，升级时三选一 |
| 结束条件 | 3:00 到达即完成；生命归零提前失败 |
| 界面 | 标题、操作说明、战斗 HUD、三选一、暂停、结算 |
| 表现 | 几何图形、路径残光、碎裂粒子、合成音效、有限震屏 |
| 技术 | 单 HTML、零依赖、离线运行、键鼠操作 |

### 2.2 本版明确不做

- 首领与任何多阶段战斗。
- 射线菱形、冲锋双锥、精英变体。
- 局外数据碎片、永久属性、协议终端、协议解锁和成长存档。
- 多地图、随机地形、剧情、角色选择、装备与稀有度。
- 手柄、移动端、联网、排行榜、商业化。
- 正式平衡与长时间内容量；3 分钟只用于验证手感。

### 2.3 暂停后不进入本版的内容

远程敌人、冲锋敌人、精英、首领、局外成长。只有在三个验证目标达到通过阈值后，才进入下一轮范围评审。

## 3. 单局流程

### 3.1 3 分钟节奏

| 时间 | 敌人与压力 | 设计目的 |
|---|---|---|
| 0:00–0:20 | 少量追迹三角，首个升级约在 20–30 秒出现 | 无文字墙学会移动、蓄力、闪切 |
| 0:20–0:35 | 追迹三角密度缓慢提高 | 第一次感受三目标连穿 |
| 0:35–1:20 | 加入壁垒方块，与三角混合 | 迫使玩家比较长度与宽度 |
| 1:20–2:10 | 方块比例提高，出现两翼包夹 | 检验构筑后形状是否真的改变路线 |
| 2:10–2:45 | 高密度混合敌潮 | 提供连续多杀与清屏高光 |
| 2:45–3:00 | 最后一波集中敌群 | 在结算前留下明确高潮 |
| 3:00 | 停止生成，显示“沙盒完成” | 控制验证时长，不引入首领 |

### 3.2 秒级循环

**移动聚怪 → 鼠标瞄准 → 按住左键蓄力 → 观察预览与危险 → 松开闪切 → 多杀反馈 → 拾取经验 → 三选一改变形状 → 再次聚怪**

### 3.3 胜负与暂停

- **完成**：战斗计时达到 3:00，结算只触发一次。
- **失败**：玩家生命降至 0，立即结束。
- **暂停**：Esc 打开暂停菜单，冻结战斗、敌人、弹体与计时。
- **三选一**：升级时冻结战斗，不推进计时。
- **重开**：结算页可立即重开或返回标题。
- **无局外结算**：本版不保存战力、不结算永久资源；仅保存音画设置。

## 4. 玩家操作与规则

### 4.1 输入映射

| 输入 | 行为 | 成功反馈 | 失败或受限反馈 |
|---|---|---|---|
| WASD | 八方向移动，斜向归一化 | 角色移动与轻微拖尾 | 竞技场边界阻尼 |
| 鼠标移动 | 瞄准 | 角色尖端、准星和预览跟随 | 无 |
| 按住左键 | 开始并维持蓄力 | 世界减速、预览展开、升调声 | 冷却中显示冷却环，不进入蓄力 |
| 松开左键 | 按当前参数闪切 | 瞬移、路径残光、命中反馈 | 无资源消耗，仅进入冷却 |
| 右键 | 取消蓄力 | 时间恢复，预览淡出 | 无 |
| Esc | 暂停或继续 | 冻结画面并显示菜单 | 无 |
| 1 / 2 / 3 或点击 | 选择强化 | 选择卡高亮，形状立即变化 | 未选择前战斗保持冻结 |

### 4.2 战斗状态

```text
移动 ⇄ 蓄力瞄准 → 闪切 → 冷却 → 移动
          └→ 取消蓄力 → 移动
移动 / 蓄力 / 冷却 → 受伤 → 移动
任意状态 → 生命归零 → 失败结算
任意状态 → 升级 → 三选一 → 回到原状态
战斗计时 3:00 → 沙盒完成
```

### 4.3 基础数值

以下数值是首轮试玩默认值，允许依据手感测试调整，但必须先记录改动原因。

| 参数 | 默认值 | 说明 |
|---|---:|---|
| 最大生命 | 100 | 接触敌人受伤 |
| 移动速度 | 250 像素/秒 | 以 1280×720 逻辑分辨率为基准 |
| 蓄力移动速度 | 常态 65% | 保持微调落点的能力 |
| 受伤无敌 | 0.65 秒 | 防止同帧连续扣血 |
| 满蓄力时间 | 0.90 秒 | 现实时间，不受世界减速影响 |
| 世界时间倍率 | 100% → 20% | 用 0.12 秒平滑过渡 |
| 最短蓄力 | 0.10 秒 | 低于此值按最短闪切处理 |
| 基础切割长度 | 260 像素 | 同时是最大闪烁距离 |
| 基础切割宽度 | 24 像素 | 以路径中心线向两侧展开 |
| 基础伤害 | 40 | 同一敌人每刀最多结算一次 |
| 切割冷却 | 0.35 秒 | 从闪烁结束后开始 |
| 闪烁无敌 | 0.08 秒 | 可穿敌人，不可穿出竞技场 |
| 蓄力伤害系数 | 70% → 100% | 随蓄力完成度线性提升 |

### 4.4 蓄力规则

- 蓄力期间世界减速，但玩家仍会受伤；减速不是安全时间。
- 世界减速影响敌人、生成和战斗计时；不影响鼠标输入、界面动画与蓄力判定。
- 玩家蓄力时保留 65% 移速，用于微调路线，但不能快速逃离包围。
- 满蓄力后仍可继续按住，伤害保持 100%；没有额外资源条。
- 本版不引入能量、热量或充能次数，先验证蓄力本身是否有吸引力。

### 4.5 闪切判定

1. 起点为释放时的玩家位置，终点为瞄准方向上的切割长度终点，并限制在竞技场内。
2. 伤害区域是起点到终点的胶囊形路径，不是终点范围攻击。
3. 玩家逻辑位置瞬时到达终点，视觉残影随后衰减。
4. 同一敌人每次闪切最多结算一次伤害。
5. 闪烁期间可穿过敌人，但不能穿出竞技场边界。
6. 预览显示中心线、宽度边界、落点以及路径内预计命中目标。
7. 预览不自动修正方向，不提供自动锁敌。

### 4.6 连穿规则

- 单次闪切命中 3 个及以上敌人时触发连穿。
- 从第 3 个目标起，每多命中 1 个目标，本次伤害增加 8%，最多增加 40%。
- 连穿只影响本次切割，不形成永久成长。
- 命中数提高音阶、碎裂规模与计数，但震屏与顿帧有全局上限。
- 连穿是“闪切是否爽”的主要可观察指标，HUD 记录本局最高连穿。

## 5. 两类敌人

### 5.1 追迹三角

| 项目 | 设计 |
|---|---|
| 轮廓 | 实心三角，区别于玩家的空心几何体 |
| 行为 | 持续转向玩家并靠近，形成可被聚拢的基础敌潮 |
| 作用 | 提供聚怪素材与早期多杀目标 |
| 生命 | 低，基础构筑下一刀可击杀 |
| 伤害 | 接触伤害，受玩家无敌帧限制 |
| 反馈 | 转向明显；死亡时沿切割方向断开 |

### 5.2 壁垒方块

| 项目 | 设计 |
|---|---|
| 轮廓 | 较大的方形轮廓，内部有第二层线框 |
| 行为 | 低速、高生命，持续压缩安全空间 |
| 作用 | 让玩家感受长度、宽度与伤害差异 |
| 生命 | 约为基础追迹三角的 4–5 倍 |
| 伤害 | 接触伤害，高于追迹三角 |
| 反馈 | 受击有金属感，死亡时碎裂成较大方块 |
| 限制 | 不使用远程、冲锋或召唤行为 |

### 5.3 生成与难度

- 0:00–0:35 只生成追迹三角。
- 0:35 后按比例加入壁垒方块。
- 随时间逐步缩短生成间隔、提高同屏上限；不增加新敌人种类。
- 所有敌人在镜头外围生成，避免突然出现在玩家身上。
- 本版不设置精英，不添加金色描边或额外词缀。

## 6. 8 项强化

### 6.1 设计目标

八项强化分为三类：

- **形状**：让切割长或宽的变化肉眼可见。
- **节奏**：让蓄力和连续闪切的手感改变。
- **附加效果**：用少量视觉事件强化“切开了什么”的感受。

所有强化在首次获得时就应产生可感知变化，不设置纯隐藏数值。

### 6.2 强化表

| 名称 | 效果 | 取舍 | 设计目的 |
|---|---|---|---|
| 扩容协议 | 切割宽度 +35% | 长度 −12% | 宽幅变化立即可见 |
| 穿刺协议 | 切割长度 +40% | 宽度 −20% | 远距离突进感立即可见 |
| 超频协议 | 满蓄力时间 −18% | 基础伤害 −8% | 蓄力更快，节奏更紧 |
| 重载协议 | 基础伤害 +30% | 满蓄力时间 +15% | 更重的单次切割 |
| 磁轨协议 | 长度 +22%，冷却 −8% | 移动速度 −6% | 长距离连续位移 |
| 窄锋协议 | 宽度 −15%，伤害 +22% | 覆盖容错下降 | 精准、短线高伤路线 |
| 余波 | 路径末端追加一次横向短切 | 追加伤害为基础伤害 30%，唯一 | 让路径终点也有形状反馈 |
| 分叉协议 | 落点向两侧发出短切线 | 主路径宽度 −12%，唯一 | 改变切割轮廓，肉眼最明显 |

### 6.3 叠加规则

- 扩容、穿刺、超频、重载、磁轨、窄锋可重复出现并叠加。
- 余波、分叉为唯一强化，获得后不再进入候选池。
- 同类百分比加成先累计，再作用于基础值。
- 长度、宽度、蓄力时间与冷却设置安全下限，避免不可操作。
- 每次升级提供三张不同卡片；池中不足三张时允许重复已持有强化。
- 不设置刷新、锁定、稀有度或装备槽。

### 6.4 升级后的可读反馈

- 卡片展示简要形状图：长度、宽度变化必须视觉可辨。
- 选择后立即更新实战切割预览，不需要等到下一次蓄力。
- 显示一句短提示，例如“切割变宽，落点变近”。
- 玩家不应只看到“伤害 +30%”而不知道操作上发生了什么。

### 6.5 升级频率

- 首个三选一出现在 20–30 秒内。
- 3 分钟内目标触发 5–6 次升级，保证形状变化能被反复感知。
- 三选一时战斗冻结，计时不推进。
- 经验碎片吸附范围足够大，避免玩家为了捡经验远离敌人而打断节奏。

## 7. 反馈与音画

### 7.1 视觉规范

| 用途 | 颜色 | 原则 |
|---|---|---|
| 背景 | 深蓝黑 | 低对比网格，不盖过战斗主体 |
| 玩家 | 青色空心几何体 | 尖端明确指向瞄准方向 |
| 追迹三角 | 品红轮廓 | 形状与玩家明显不同 |
| 壁垒方块 | 橙色双层线框 | 明确传达高生命与阻挡感 |
| 经验 | 紫色碎片 | 小、亮、快速吸附 |
| 预警 | 琥珀与高对比描边 | 永远在装饰特效之上 |

### 7.2 一次命中的反馈顺序

**释放瞬态声 → 起点残影 → 路径残光 → 短顿帧 → 几何碎裂 → 金属泛音 → 连穿计数 → 经验吸附**

### 7.3 反馈参数

| 反馈 | 默认值 | 约束 |
|---|---|---|
| 普通命中顿帧 | 35 毫秒 | 不冻结输入缓存 |
| 连穿顿帧 | 最高 55 毫秒 | 不随命中数无限增长 |
| 普通震屏 | 1–2 像素，60–90 毫秒 | 可关闭 |
| 连穿震屏 | 最高 5 像素，120 毫秒 | 全局上限 |
| 路径残光 | 120–180 毫秒 | 不遮住敌方位置 |
| 几何碎片 | 每个敌人 3–6 片 | 限制同屏总粒子数 |
| 空切 | 细短残光、轻释放声 | 不触发命中顿帧 |

### 7.4 可访问性

- 震屏强度：100% / 50% / 关闭。
- 闪光与色差：独立开关，默认低强度。
- 高对比预警：增加描边和形状提示，不只换颜色。
- 主音量、音乐、音效分别调整。
- 视觉设置不得改变命中、伤害或世界减速规则。

### 7.5 音频

- 风格：电子 glitch、金属切割瞬态、深色电子节拍。
- 蓄力：音高随进度上升，取消时快速下降。
- 释放：短噪声瞬态；切割越长，低频越明显。
- 命中：金属泛音；多杀合并成一次主音效加分层音阶。
- 空切：无金属命中层，明确区分。
- 受伤：低频中断与短失真，不与击杀声混淆。
- 同类音效限制并发，避免高密度敌潮中削波。

## 8. 界面

### 8.1 标题界面

- 游戏名与一句话说明。
- 三个验证目标：蓄力意愿、闪切手感、形状变化。
- 开始按钮。
- 操作说明：WASD、鼠标、左键按住释放、右键取消、Esc 暂停。
- 设置入口。
- 不展示未实现的首领、局外或更多敌人。

### 8.2 战斗 HUD

- 左上：生命、等级、经验条。
- 上方：3:00 倒计时。
- 右上：击杀数与最高连穿。
- 玩家附近：蓄力环、冷却环、切割预览。
- 准星附近：本次路径预计命中数与连穿提示。
- 不显示数据碎片、局外货币或永久加成。

### 8.3 三选一界面

- 三张并列卡片，写明名称、正向效果、取舍与当前等级。
- 提供简化切割形状图。
- 支持数字键 1/2/3 与鼠标点击。
- 选择后立即回到战斗，不展示额外奖励动画拖慢节奏。

### 8.4 结算界面

- 完成或失败状态。
- 存活时间、击杀数、最高连穿、闪切次数、有效命中率。
- 已选强化列表。
- 重开与返回标题。
- 不显示局外货币结算或永久成长提示。

## 9. 浏览器 Demo 技术边界

- 单 HTML、零外部依赖、可离线打开。
- Canvas 2D 绘制，Web Audio 合成音效，不加载来源不明素材。
- 固定时间步长更新，分离逻辑与绘制，避免帧率改变伤害和移动。
- 使用对象池管理敌人、经验、粒子与残光。
- 切割判定使用纯函数并配边界测试，预览与实际判定保持一致。

## 10. 开发任务与验收

### 10.1 开发任务

| 任务 | 完成标准 | 依赖 |
|---|---|---|
| 3 分钟沙盒循环 | 计时、生成、结束、结算只触发一次 | 无 |
| 蓄力闪切 | 预览、判定、无敌、边界和冷却一致 | 固定步长 |
| 两类敌人 | 追迹与壁垒有明确不同的应对方式 | 生成器 |
| 8 项强化 | 全部真实生效，形状即时更新，唯一项不重复 | 属性计算 |
| 三选一 | 冻结战斗、三卡可选、键盘鼠标均可操作 | 升级系统 |
| 反馈与音频 | 空切、命中、连穿、受伤可区分 | Web Audio 用户手势 |
| 设置与暂停 | 失焦暂停、震屏与音量即时生效 | 无 |
| 自动检查 | 语法、纯函数、范围静态检查通过 | Node 可用 |

### 10.2 功能验收

- 0:35 前只出现追迹三角，之后加入壁垒方块。
- 3:00 必定进入完成结算，不出现首领或新敌人。
- 生命归零进入失败结算；完成和失败不会重复结算。
- 同一敌人不会被同一路径重复伤害。
- 8 项强化均能在实战中观察到效果。
- 余波与分叉不会重复出现在候选池。
- 选择升级后，切割预览立即改变。
- 蓄力时世界减速，但玩家仍可受伤。
- 暂停与三选一期间计时不推进。
- 界面不出现局外成长、数据碎片或未实现内容入口。

### 10.3 新手试玩脚本

1. 不阅读额外说明，从标题开始游戏。
2. 20 秒内完成一次移动与闪切。
3. 尝试至少一次完整蓄力和一次快速点按，并说出差异。
4. 第一次升级时选择一张卡，说出切割发生了什么变化。
5. 尝试一次至少命中 3 个目标的闪切。
6. 完成或失败后立即重开一次，观察是否出现结算异常。
7. 访谈玩家：是否愿意主动蓄力、闪切是否爽、形状变化是否肉眼可见。

### 10.4 通过阈值

- 至少 4/5 名首次试玩者在 30 秒内完成有效闪切。
- 至少 4/5 名首次试玩者在首次升级后说出长度、宽度或蓄力节奏中的一种变化。
- 至少 3/5 名首次试玩者在 3 分钟内主动完成一次 3 目标以上连穿。
- 至少 3/5 名首次试玩者表示愿意在后续闪切中继续使用蓄力。
- 至少 4/5 名首次试玩者能区分空切、命中和自身受伤。
- 连续重开 10 局，无无法操作、重复结算、升级卡死或暂停后计时异常。
- 记录测试设备、浏览器、帧率与同屏敌人数；未实测前不宣称性能达标。

### 10.5 停止条件

出现以下任一情况，先修复或重调，不进入远程、冲锋、精英、首领和局外开发：

- 玩家普遍只点按，不愿蓄力。
- 玩家无法感知 8 项强化对形状或节奏的改变。
- 命中反馈被预警遮挡，或玩家说不清受伤来源。
- 3 分钟流程无法稳定开始、暂停、结束与重开。

## 11. 风险与调整

| 风险 | 观察信号 | 首选调整 |
|---|---|---|
| 蓄力收益不足 | 玩家只点按，觉得按住拖慢节奏 | 提高满蓄力收益或缩短满蓄力时间 |
| 减速缺乏压力 | 玩家永远等到安全再切 | 保持受伤、提高包围密度，不改资源系统 |
| 形状变化不可见 | 升级后只感觉伤害变了 | 优先调整宽度、长度和预览表现 |
| 强化出现唯一最优 | 所有试玩者只选同一张 | 调整取舍幅度、候选权重和出现频率 |
| 特效遮挡判断 | 玩家无法解释受伤 | 降低装饰层，预警始终置顶 |
| 范围再次膨胀 | 开始讨论首领和局外 | 回到三个验证目标，未过阈值不扩内容 |
